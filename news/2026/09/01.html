★01AWS, Agent Registry 정식 출시 — 에이전트·툴·스킬 검색·거버넌스 통합 카탈로그 제공Manage agents, tools and skills at scale with AWS Agent Registry✍️ 블로그 · aws.amazon.comAWS Agent Registry가 정식 출시되어 조직 내 에이전트, 툴, 스킬, 커스텀 리소스를 등록·검색·관리할 수 있는 단일 카탈로그를 제공한다.

팀들이 각자 고립되어 개발하면서 발생하는 중복 구축, 소유권 불명확, 거버넌스 부재 문제를 해결하기 위해 설계됐다. 내부적으로 Governance Plane(등록된 전체 리소스와 규정 준수·보안 메타데이터 관리)과 Discovery Plane(승인된 리소스만 노출하는 큐레이션된 검색 뷰) 두 개의 플레인으로 동작한다. 시맨틱 검색과 접근 제어를 내장해 개발자가 기존 리소스를 재사용하고, 관리자는 접근 권한·수명주기·승인 워크플로우를 통해 리소스를 관리할 수 있다.

WHY IT MATTERS

에이전트형 AI 시스템이 수십 개에서 수백 개로 늘어나면 발견과 신뢰 확보가 병목이 되는데, 이는 엔터프라이즈 규모의 AI 거버넌스 인프라 표준화를 시사한다.

WHAT'S DIFFERENT

기존에는 팀별로 각자 에이전트·툴을 관리해 버전 드리프트와 감사 추적 불가 문제가 있었지만, Agent Registry는 소유권과 계보, 승인 이력을 중앙에서 추적하는 단일 카탈로그를 제공한다는 점이 다르다.

02AWS, Amazon Bedrock Managed Knowledge Base로 멀티테넌트 에이전틱 문서 챗봇 아키텍처 공개Build multi-tenant agentic chat applications on enterprise data with Amazon Bedrock Managed Knowledge Base✍️ 블로그 · aws.amazon.com이 블로그는 여러 테넌트의 문서를 격리하면서 에이전틱 검색을 수행하는 문서 챗 애플리케이션을 Amazon Bedrock Knowledge Bases 위에 구축하는 아키텍처를 설명한다.

Bedrock Managed Knowledge Base가 수집·저장·임베딩·랭킹·멀티홉 검색을 관리형으로 제공해 별도 인프라 구축 없이 검색 스택을 운영할 수 있다. 사용자가 질문하면 API가 단순 조회는 단일 검색, 복잡한 질문은 하위 질의로 분해해 여러 번 검색하는 에이전틱 워크플로를 실행하며, 응답은 검색된 내용에 근거하고 인용을 포함한다. 애플리케이션은 업로드 UI, 채팅 UI, 인증(Amazon Cognito), 사용자별 격리, 비즈니스 로직만 담당하면 된다. 커스텀 커넥터를 통해 문서를 직접 수집하면 몇 초 내에 검색 가능해진다.

WHY IT MATTERS

멀티테넌트 문서 챗은 각 테넌트의 검증된 신원 기반 격리와 모든 검색 홉에서의 필터 적용이 필수적인데, 이를 직접 구현하려면 상당한 인프라 작업이 필요하다. 관리형 서비스로 이런 격리·검색 인프라 부담을 줄이는 방식은 엔터프라이즈 RAG 애플리케이션을 빠르게 출시하려는 개발팀에게 실질적인 참고가 된다.

WHAT'S DIFFERENT

기존에는 벡터·전문 검색 엔진, 다중 모달 파싱·임베딩 파이프라인, 동기화된 인덱스를 팀이 직접 구축·보안·운영해야 했지만, Bedrock Managed Knowledge Base는 이런 인프라와 에이전틱 멀티홉 검색, 권한 준수를 서비스 자체에서 제공한다는 점이 다르다.

WHY IT MATTERS

WHY IT MATTERS

단일 정답을 가정하는 기존 QA 평가 방식으로는 LLM의 파라메트릭 기억이 갖는 편향과 불완전성을 놓칠 수 있어, 지식 다양성과 공정성을 검증하려는 연구자에게 중요한 진단 도구가 된다.

WHAT'S DIFFERENT

기존 사실 QA 벤치마크가 단일 정답 기준으로 정확도만 측정한 것과 달리, ElephantBench는 롱테일 사실에 대한 다중 설명 복원 여부를 그래프 기반 파이프라인으로 자동 구축해 출처 추적이 가능한 지식 편향 진단을 가능하게 한다.

01Amazon, Rust 검증 도구 Verus 소개 — Nitro Isolation Engine 핵심 모듈 정확성 증명에 활용Developing provably correct Rust code with Verus✍️ 블로그 · amazon.scienceVerus는 Rust 코드를 위한 오픈소스 자동 프로그램 검증기로, 코드가 명시된 수학적 사양을 모든 가능한 입력에 대해 만족하는지 기계적으로 확인한다.

WHAT'S DIFFERENT

기존 Rust 타입 시스템이 메모리 안전성 등 '더 안전한' 수준의 보장을 제공하는 것과 달리, Verus는 사양 기반 형식 증명을 통해 코드가 실제로 의도한 대로 동작함을 모든 입력에 대해 검증한다는 점에서 차별화된다.
