WHY IT MATTERS

에이전틱 코딩 시스템의 실용성은 반복 세션 간 맥락 유지 효율에 달려 있어, 토큰 비용과 생성 품질을 동시에 개선하는 메모리 설계는 실제 배포에 중요한 이슈다.

전체 대화 이력을 그대로 유지하는 기존 방식과 달리, 네 가지 재사용 맥락 범주만 선별적으로 저장해 불필요한 맥락으로 인한 품질 저하를 방지한다.

★01Apple, DACA-GRPO 공개 — 확산 언어모델 RL 학습에 디노이징 단계별 신용 할당 적용DACA-GRPO: Denoising-Aware Credit Assignment for Reinforcement Learning in Diffusion Language Models✍️ 블로그 · machinelearning.apple.comApple은 확산 언어모델(diffusion LLM)을 위한 강화학습 방법 DACA-GRPO를 제안했다.

기존 GRPO 기반 RL 기법은 디노이징 궤적의 모든 단계를 동일하게 취급하고, 정책 최적화에 쓰이는 평균장(mean-field) 우도 추정치가 편향되고 분산이 크다는 문제가 있다. 저자들은 이 두 가지 근본적 약점, 즉 디노이징 단계 간 시간적 신용 할당 부재와 우도 추정의 체계적 편향을 지적한다. DACA-GRPO는 이를 해결하기 위한 경량의 플러그앤플레이 방식 개선으로, 기존 GRPO 스타일 트레이너 어디에나 적용 가능하다.

WHY IT MATTERS

확산 언어모델은 자기회귀 모델의 대안으로 주목받고 있지만 RL 학습 방법론은 아직 미성숙한 상태로, 이런 개선은 확산 LLM의 실용적 학습 가능성을 넓힌다.

WHAT'S DIFFERENT

모든 디노이징 단계를 동일하게 취급하고 편향된 평균장 우도 추정을 쓰는 기존 GRPO 기반 확산 RL 방법 대비, 단계별 신용 할당을 도입한 점이 다르다.

WHY IT MATTERS

소수 스텝 생성으로 추론 비용을 줄이려는 증류 접근에서, 학생 모델 개선 노력이 실제로는 잘못된 지점(궤적 데이터 자체)을 겨냥할 수 있음을 시사한다.

WHAT'S DIFFERENT

기존에는 학생 모델의 용량 부족을 성능 저하 원인으로 보았으나, 이 연구는 궤적 생성 과정의 평가되지 않은 확률적 점프가 근본 원인이라고 지적한다.

01Agentic Search Spaces for Tabular Machine LearningLLM 에이전트가 표 데이터 모델 HPO 탐색 공간 확장 — 45개 데이터셋서 평균 0.6%, 소형 회귀서 2.0% 성능 향상📄 논문 · arxiv.org이 연구는 LLM 기반 에이전트가 정형 데이터(tabular) 모델의 HPO 탐색 공간을 저자가 제공한 기본 공간보다 더 낫게 설계할 수 있는지 검증한다.

각 모델을 전처리, 임베딩, 아키텍처, 학습, 추론을 포괄하는 모듈형 파이프라인으로 표현하고, 에이전트가 각 모듈의 후보 코드 구현을 제안하면 고전적 HPO 알고리즘으로 이를 기본 하이퍼파라미터와 함께 공동 최적화한다. 45개 데이터셋에서 확장된 탐색 공간은 거의 모든 모델 계열의 성능을 개선했으며, 평균 0.6%, 소형~중형 회귀 데이터셋에서는 2.0%의 상대적 향상을 보였다. 이 개선은 동일한 튜닝·앙상블 예산 내에서 이뤄져 추가 비용이 들지 않는다. TabArena 벤치마크에서도 5개 모델 계열 중 4개의 공식 Elo 점수가 향상됐고, 가장 강력한 두 에이전틱 앙상블은 AutoGluon의 기존 모델 앙상블을 능가했다.

WHY IT MATTERS

LLM 에이전트가 코드 생성·디버깅을 넘어 모델 설계 공간 자체를 확장하는 실질적 도구로 쓰일 수 있음을 보여주며, 표 데이터 ML 파이프라인 설계 자동화의 가능성을 시사한다.

WHAT'S DIFFERENT

모델 저자가 정의한 기존 표준 HPO 탐색 공간 대비, 에이전트가 제안한 확장 탐색 공간을 동일한 튜닝 예산으로 비교해 성능 우위를 입증했다는 점이 다르다.

01Splitting the Difference: Interpretable Causal Forests for Treatment Effect Heterogeneity and Bias관찰연구용 해석 가능 인과포레스트 제안 — 이중 분할기준으로 이질성·편향 동시 처리, 시뮬레이션서 기존 방법 능가📄 논문 · arxiv.org이 논문은 개별 처치효과(ITE)를 예측하면서 동시에 왜 특정 개인에서 효과가 더 큰지 해석까지 가능한 결정트리/랜덤포레스트 기반 알고리즘을 제안한다.
