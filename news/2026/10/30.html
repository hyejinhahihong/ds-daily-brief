01MoEngage, AgentCore Gateway로 400여개 내부 API를 에이전트 도구화 — 플랫폼 엔지니어링 6개월 절감How MoEngage turned over 400 APIs into agent tools with AgentCore Gateway✍️ 블로그 · aws.amazon.comMoEngage는 25개 엔지니어링팀이 7개 AWS 리전의 프라이빗 VPC에서 운영하는 약 400개 내부 REST API를 AI 에이전트가 안전하게 사용할 수 있도록 Amazon Bedrock AgentCore의 AgentCore Gateway를 도입했다.

팀별로 20여 개의 MCP 서버를 각각 구축하는 방식은 배포·패치 부담과 MCP 전문성 요구로 인해 기각됐고, 대신 각 팀은 OpenAPI 스펙만 잘 작성하고 AI Platform팀이 MCP 레이어 전체를 중앙에서 소유하는 원칙을 세웠다. 이를 통해 공용 엔드포인트 없이, 서버 측 권한 제어와 프라이빗 연결을 유지하면서 에이전트 도구를 만들어냈다. 이 접근으로 약 6개월의 플랫폼 엔지니어링 공수를 절감했고, 새 API 온보딩이 수일에서 수시간으로 단축됐다.

WHY IT MATTERS

내부 API가 이미 존재하는 조직이 에이전트를 도입할 때 겪는 핵심 난제, 즉 수백 개 API를 보안·규모 문제 없이 노출하는 방법을 실제 운영 사례로 보여준다. 팀별 MCP 서버 구축의 확장성 한계를 명확히 지적해 중앙집중형 게이트웨이 설계의 당위성을 제시한다.

WHAT'S DIFFERENT

팀마다 자체 MCP 서버를 만드는 기존의 분산형 접근 대비, 팀은 OpenAPI 스펙 작성까지만 책임지고 MCP 변환·권한·연결 계층은 AI Platform팀이 AgentCore Gateway로 중앙 관리하는 구조로 차별화된다.

기존 Playwright 기반 회귀 테스트는 그대로 유지하되, 선택자에 의존해 사소한 UI 변경에도 깨지는 한계를 보완하기 위해 Amazon Nova Act와 Amazon Bedrock AgentCore Browser Tool을 결합한 의도 기반 테스트를 추가했다. Nova Act는 "리워드 잔액이 보이는지 확인"과 같은 자연어 지시문으로 테스트를 실행해 UI 변경에 강건하고 비개발자도 이해할 수 있다. AgentCore Browser Tool은 격리된 일회성 브라우저 세션, 라이브 뷰, S3 세션 기록, CloudTrail 감사 기능을 제공해 별도 설정 없이 멀티테넌트 플랫폼 서비스로 제공 가능하다. 이 글은 18단계 테스트 워크플로와 핵심 통합 코드, 운영 모범사례 및 측정 결과를 소개한다.

WHY IT MATTERS

선택자 기반 테스트의 유지보수 부담을 자연어 지시문으로 낮추면서도 기존 회귀 테스트 체계를 대체하지 않고 보완하는 현실적인 도입 사례로, 여러 제품팀이 동일한 API로 AI 에이전트 기능을 소비하는 플랫폼화 전략을 보여준다.

WHAT'S DIFFERENT

기존 Playwright 기반 선택자 테스트는 페이지 구조에 강하게 결합돼 사소한 UI 변경에도 깨지는 반면, Nova Act는 자연어 단계로 테스트를 기술해 코스메틱 변경에 강건하고 팀별 브라우저 인프라·신원 통합을 별도로 구축할 필요가 없다는 점이 다르다.

01NVIDIA, 머신러닝 원자간 포텐셜에 Tensor Core 가속 적용 — DFT 수준 정확도·속도 격차 해소 시도Unlocking Tensor Core Performance for Machine Learning Interatomic Potentials✍️ 블로그 · developer.nvidia.com이 글은 분자·재료의 거동을 연구하는 원자 단위 시뮬레이션에서 비용-정확도 트레이드오프 문제를 다룬다.

밀도범함수이론(DFT) 같은 양자역학 기반 방법은 정확한 에너지·힘을 제공하지만 계산 비용이 커서 대규모 시스템이나 장시간 시뮬레이션에는 한계가 있다고 설명한다. 이를 보완하기 위해 머신러닝 기반 원자간 포텐셜(MLIP)을 활용하는 접근을 소개하며, NVIDIA의 Tensor Core를 활용해 성능을 끌어올리는 방법을 다룬다.

WHY IT MATTERS

DFT 수준의 정확도를 유지하면서 대규모·장시간 시뮬레이션이 가능해지면 재료 설계와 화학 반응 연구의 실험 주기를 크게 단축할 수 있다.

02Neural Compression of Long ADMM Trajectory for Multiparametric Quadratic ProgramTQPNet, ADMM 긴 최적화 궤적을 신경망으로 압축 — mpQP 실시간 풀이 가속📄 논문 · arxiv.org · NeurIPS 2026이 논문은 대규모 다변수 2차계획법(mpQP)을 실시간으로 풀기 위해 수천 번의 ADMM 반복이 필요한 문제를 해결하고자 TQPNet을 제안한다.

저primal-dual 변수 (x,β) 상에서 동작하는 저차원 ADMM 기법을 유도하고, 그 반복 과정이 ReLU 레이어로 등가 표현됨(ADMM(ReLU))을 보인다. TQPNet은 ReLU 활성화 MLP와 소수의 unrolled ADMM(ReLU) 정제 레이어를 결합해 긴 최적화 궤적을 압축된 신경망 웜스타트로 변환한다. 솔버가 생성한 레이블 없이 최적성 조건 기반 잔차 손실로 오프라인 학습하며, 이 잔차 기반 프레임워크는 자기지도 학습과 온라인 해 검증(적응형 ADMM(ReLU) 정제)을 동시에 가능하게 한다. 대규모 mpQP 및 실시간 MPC 실험에서 기존 최적화 기반 방법보다 높은 정확도와 일반화, 훨씬 빠른 추론 속도를 달성했다.

WHY IT MATTERS

모델예측제어(MPC)나 학습 기반 시스템에서 실시간 최적화는 주요 병목인데, 이를 신경망 웜스타트로 대체하면 제어 주기 내 연산 부담을 크게 줄일 수 있어 실용적 가치가 크다.

WHAT'S DIFFERENT

기존 ADMM 반복 기반 최적화 솔버 대비, ADMM 반복 자체를 ReLU 레이어로 재해석해 신경망에 내재화하고 솔버 레이블 없이 잔차 손실만으로 자기지도 학습한다는 점이 다르다.

03Integral Probability BoundariesNeurIPS 2026, IPM 일반화한 'Integral Probability Boundaries' 제안 — 희귀 그룹 공정성 격차 추정 15%p 개선📄 논문 · arxiv.org · NeurIPS 2026기존 Integral Probability Metrics(IPM)는 두 분포 간 차이를 하나의 최악 기댓값 격차로 압축하는데, 이는 희귀 이벤트나 소수 그룹에서는 느슨하거나 공허한 경계를 낳는다.

이 논문은 IPM을 비선형으로 일반화한 Integral Probability Boundaries(IPB)를 제안하며, 극단값에서도 타이트한 경계를 제공한다. 저자들은 IPB의 기본 성질을 유도하고 실용적 환경에서 이를 추정하는 알고리즘을 제시한다. 정렬(alignment), 판정자 없는 성능 추정, 공정성 등에 IPB를 적용해 성능·공정성 격차에 대한 날카로운 경계를 얻을 수 있음을 보인다. 실제 생성 모델링 과제에서 희귀 그룹의 공정성 격차 추정이 기존 최선 대비 15%p 더 정밀함을 보였다.

WHY IT MATTERS

일반화, 정렬, 공정성, 프라이버시 등 ML 전반에서 쓰이는 IPM 기반 경계가 소수 그룹·희귀 사건에서 무용지물이 될 수 있다는 점을 지적하고 이를 보완하므로, 공정성 감사나 안전성 평가의 신뢰도를 높이는 데 실질적 영향을 줄 수 있다.

WHAT'S DIFFERENT

기존 IPM이 분포 차이를 단일 최악 기댓값 격차로 압축해 희귀 사건·소수 그룹에서 경계가 느슨해지는 것과 달리, IPB는 비선형 일반화를 통해 극단값에서도 타이트한 경계를 제공한다.

01Detecting Brain Cancer Progression Through Signatures of Wearable Accelerometry Data손목 가속도계 신호에 rough path signature 적용, 뇌종양(HGG) 안정기 대 진행기 구분 가능성 제시📄 논문 · arxiv.org · NeurIPS 2026고등급 신경교종(HGG) 환자는 기능이 점진적으로 악화되지만, 표준 진단법인 조영증강 MRI는 비싸고 2~3개월에 한 번만 시행된다는 한계가 있다.

이 연구는 손목 착용형 가속도계 데이터를 걷기 구간으로 변환하고 rough path signature 기반 SigMMD(signature kernel maximum mean discrepancy)로 보행 패턴 변화를 정량화했다. 환자마다 걷기 양상이 크게 다른 문제는 안정기 동안의 개인별 보행 변동으로 정규화해 해결했으며, 이 환자별 정규화가 안정기와 진행기 구분을 크게 개선했다. BrainWear 연구 참여 환자 데이터를 통해 이 신호 기반 분석이 종양 진행의 후보 바이오마커가 될 수 있음을 proof-of-concept 수준에서 보였다.

WHY IT MATTERS

MRI처럼 비용이 크고 간헐적인 검사 대신 웨어러블로 연속 모니터링이 가능해지면 신경종양학에서 디지털 바이오마커 개발의 새로운 방향이 열릴 수 있다. 노이즈가 많고 환자별 편차가 큰 의료 시계열 데이터를 다루는 데 signature 방법론이 유효하다는 근거를 제공한다.

WHAT'S DIFFERENT

기존 요약통계 기반 시계열 분석 대비, 노이즈가 많고 환자마다 상이한 가속도계 데이터에 rough path signature와 SigMMD를 적용하고 환자별 안정기 변동으로 정규화하는 접근이 다르다.

각 모델마다 기존 편향을 증폭시키는 토폴로지가 있지만 모델별로 다르게 나타나, 편향은 제거되지 않고 자리만 옮겨 다닐 뿐이었다. 공정성 지시문, 인구통계 마스킹 같은 후처리 대응은 효과가 없었고, 에이전트별 자가 디바이어싱은 오히려 격차를 더 키웠는데, 이는 편향이 이미 각 에이전트의 일반 임상 판단 수치에 내재되어 있기 때문이다. 반면 반사실적 버전들을 시스템 내부에서 보이게 하고 숙의를 통해 통합하는 개입, 즉 다양한 관점을 모든 라운드에서 풀링하는 앙상블 방식은 재훈련이나 구조 변경 없이 격차를 67~94% 감소시켰다.

WHY IT MATTERS

임상 AI에 적용되는 모델별·출력별 감사는 개별 요소는 검증할 수 있어도 최종 합의 결정에 숨은 편향은 잡아내지 못한다는 점에서, 멀티에이전트 설계가 편향을 걸러내는 게 아니라 '세탁'해 버릴 위험을 보여준다.

WHAT'S DIFFERENT

기존의 공정성 지시문이나 인구통계 마스킹, 개별 에이전트 자가 디바이어싱 같은 사후 교정 방식과 달리, 반사실적 관점을 시스템 내부에서 명시적으로 드러내고 숙의 과정에서 풀링하는 접근만이 격차를 실질적으로 줄였다.

WHAT'S DIFFERENT
