★01MS, Agent Lightning v1.0 공개 — 3500줄 경량 프레임워크로 SWE-bench 56.4% 달성(기존 41.8%)Agent Lightning v1.0: A 3,500-Line Lightweight Agentic RL Framework for Training Agents with Real Harnesses✍️ 블로그 · microsoft.comMicrosoft Research Asia가 실제 배포에 쓰이는 에이전트 하네스를 그대로 강화학습에 참여시키는 'Harnessed Agentic RL' 패러다임을 제안하고, 이를 구현한 Agent Lightning v1.0을 오픈소스로 공개했다.

전체 프레임워크는 약 3,500줄의 코드로 구성되며, LLM 프록시를 에이전트와 모델 사이에 배치해 기존 하네스 코드 변경 없이 모델 호출을 관찰·기록한다. 에이전트는 커맨드형 Kubernetes job으로 실행되어 상용 샌드박스 서비스 없이 자체 클러스터나 로컬 인프라에서도 대규모 롤아웃이 가능하다. 코딩 에이전트 학습 예시에서는 Qwen3.5-9B 모델을 SWE-bench Verified Pass@1 41.8%에서 56.4%로 14.6%p 개선했으며, 약 6,000개의 오픈소스 학습 샘플만 사용했다.

WHY IT MATTERS

에이전트 RL 학습과 실제 배포 에이전트 간 불일치 문제를 해결함으로써, 학습된 에이전트가 배포 환경에서도 동일하게 동작함을 보장할 수 있다는 점에서 실용적 가치가 크다. 가벼운 코드베이스와 Kubernetes 네이티브 지원은 상용 샌드박스 의존 없이 누구나 에이전트 RL 파이프라인을 재현·확장할 수 있게 한다.

WHAT'S DIFFERENT

기존 verl, AReaL, slime 같은 전통적 agentic RL 시스템은 학습 프레임워크 내부에 에이전트 루프를 재구현해야 했지만, Agent Lightning v1.0은 LLM 프록시를 통해 mini-SWE-agent, OpenHands, Claude Code 등 실제 하네스를 변경 없이 그대로 학습에 활용한다.

02Apple, RISED 공개 — 멀티환경 LLM 에이전트 학습 시 루브릭 기반 프롬프트 선별·자기증류로 데이터 낭비 해소RISED: Rubrics for Agentic Multi-Environment Selection and Self-Distillation✍️ 블로그 · machinelearning.apple.comRISED는 여러 상호작용 환경에서 LLM 에이전트를 동시에 학습시킬 때 발생하는 비효율을 다루는 방법이다.

기존 커리큘럼 및 데이터 선택 전략은 환경 단위로 학습을 배분하거나 로컬 보상 신호만 우선시해, 서로 다른 환경의 현재 롤아웃 간 관계를 프롬프트-그룹 선택에 반영하지 못했다. 환경마다 학습 속도가 달라 한 배치 안에 전부 성공 또는 전부 실패한 롤아웃 그룹이 공존할 수 있는데, 이 경우 그룹 상대적 보상 신호를 얻지 못해 해당 데이터가 학습에 활용되지 못하는 문제가 있다. RISED는 루브릭을 활용해 에이전트 다중환경 선택과 자기증류(self-distillation)를 수행함으로써 이런 신호 부재 상황을 해결하고자 한다.

WHY IT MATTERS

멀티환경 제너럴리스트 에이전트를 학습시킬 때 보상 신호가 없는 데이터를 어떻게 활용하느냐가 학습 효율을 좌우하므로, 이 문제를 구조적으로 다루는 접근은 실용적 가치가 크다.

WHAT'S DIFFERENT

기존 환경 단위 커리큘럼이나 로컬 보상 기반 선택 전략과 달리, RISED는 여러 환경에 걸친 롤아웃 간 관계를 명시적으로 고려해 프롬프트-그룹을 선택한다.

01TimeBraid: Unifying Time Series and Language for Understanding and ForecastingTimeBraid, 언어모델과 시계열 파운데이션모델을 잔차 어텐션으로 통합 — 220만 쌍 데이터로 예측·추론 동시 지원📄 논문 · arxiv.orgTimeBraid는 사전학습된 언어모델과 시계열 파운데이션모델을 교차 배치된 전역 잔차 어텐션 레이어로 정렬해 하나의 공유 표현 공간을 만든 통합 모델이다.

언어모델에서는 지식과 지시 수행·추론 능력을, 시계열모델에서는 연속 신호 인식과 제로샷 예측 능력을 물려받아 두 모달리티를 함께 이해하고 생성한다. 두 표현 공간을 어디서 정렬할지, 언어를 시간적 구조에 어떻게 결합할지, 이해와 생성의 균형을 어떻게 맞출지, 공동 최적화를 어떻게 안정화할지에 대한 설계 선택을 연구했다. 이를 위해 통합 프롬프팅 방식, 안정화된 공동 학습, 220만 개의 시계열-텍스트 쌍과 490만 개의 지시 튜닝 샘플로 지도학습을 수행했다. 시계열 인식, 이해, 추론, 맥락 기반·단일모달 예측을 아우르는 벤치마크에서 TimeBraid는 훨씬 큰 범용 모델 및 태스크 전용 모델과 경쟁력 있는 성능을 보였다.

WHY IT MATTERS

시계열과 언어를 별도로 다루던 기존 구조에서 벗어나, 하나의 모델이 예측·이해·추론을 동시에 수행하게 되면 시계열 분석 파이프라인의 범용성과 활용성이 크게 확장될 수 있다.

WHAT'S DIFFERENT

기존의 대형 범용 언어모델이나 시계열 전용 모델을 각각 사용하는 방식과 달리, TimeBraid는 교차 배치된 잔차 어텐션으로 두 사전학습 모델을 하나의 공유 표현 공간에 직접 정렬하는 방식을 택했다.

02HLA: Expressive Hybrid Linear Attention via Chunk-Wise Dynamic MixingHLA, Gated DeltaNet에 쿼리 종속 청크 라우팅 추가 — LongBench-V2 5.57점, RULER 32K서 4.22점 개선📄 논문 · arxiv.org선형 어텐션은 과거 정보를 순환 상태로 압축해 장문 맥락 디코딩을 효율화하지만, 희소하고 먼 정보에 선택적으로 접근하기 어렵다는 한계가 있다.

기존 청크 기반 확장은 메모리 용량을 늘리지만 청크 혼합 계수가 입력 내용과 무관하게 고정돼 쿼리별로 과거 접근을 조정하지 못한다. 이 논문은 Gated DeltaNet(GDN)을 위한 쿼리 종속 청크 단위 어텐션인 HLA를 제안하며, 완료된 청크를 정확한 아핀 상태 전이로 표현하고 압축된 자기어텐션 풀링 표현으로부터 콘텐츠 종속 라우팅 게이트를 계산한다. Qwen3.5 0.8B~9B 모델 실험에서 HLA는 기존 GDN과 고정 청크 혼합 대비 LongBench-V2에서 최대 5.57점, RULER에서 3.97점 향상을 보였고, 1.3B 모델을 100B 토큰·4K 맥락으로 처음부터 학습한 설정에서도 RULER 성능이 4K에서 32K로 갈수록 0.83점에서 4.22점까지 개선폭이 커졌다.

WHY IT MATTERS

장문 맥락 모델링에서 순환 메모리를 쿼리에 맞춰 동적으로 구성하는 방식이 효율성과 선택적 정보 접근이라는 상충되는 목표를 함께 개선할 수 있음을 보여준다.

WHAT'S DIFFERENT

기존 GDN의 고정 청크 혼합 계수와 달리, HLA는 콘텐츠에 따라 각 청크의 아핀 전이를 항등 사상과 보간하는 게이트를 쿼리별로 계산해 과거 접근을 적응적으로 조정한다.

03MEND: RL For Flow Models via Proximal Velocity MatchingMEND, proximal velocity matching으로 flow 모델 RL 후학습 — 100 스텝만에 Flow-GRPO(4천 스텝) 능가📄 논문 · arxiv.orgMEND는 flow 모델의 보상 기반 후학습을 위한 강화학습 기법으로, proximal velocity matching에 기반한다.

각 프롬프트 그룹 내에서 보상을 상한선으로 제한해 이미 점수가 높은 샘플은 이동시키지 않고, 상한선 아래 샘플은 보상 그래디언트 방향으로 이동을 제안하되 보상 이득이 이차 변위 비용을 넘을 때만 수용한다. KL 페널티, 고정 참조 모델, advantage 가중치 없이 이렇게 얻은 velocity target에 모델을 회귀시킨다. 100회 업데이트만으로 약 4천회를 거친 Flow-GRPO를 6개 평가지표 중 5개에서 능가했고, 동일 예산 조건에서는 ReFL·DiffusionNFT 대비 모든 업데이트 시점에서 우위를 보이며 PickScore 24.03(대 23.92, 23.43)을 기록했다.

WHY IT MATTERS

수천 번의 업데이트 없이 적은 스텝으로 기존 RL 후학습 기법을 능가한다는 점은 flow 모델 학습 비용을 크게 줄일 수 있음을 시사한다. 미분 가능한 보상만 있으면 어떤 flow 백본에도 적용 가능해 범용성이 높다.

WHAT'S DIFFERENT

KL 페널티나 고정 참조 모델, advantage 가중치에 의존하는 Flow-GRPO, ReFL, DiffusionNFT와 달리, 보상 상한과 이차 변위 비용 기준으로 이동 여부를 선별적으로 수용하는 방식을 사용한다.

WHAT'S DIFFERENT
