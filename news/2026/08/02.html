★01코딩 에이전트, 컨텍스트 창 확대 대신 '컨텍스트 컴파일러'가 해법 — 프롬프트 구성 재설계 제안Coding Agents Don’t Need Bigger Context Windows — They Need a Context Compiler✍️ 블로그 · towardsdatascience.com많은 코딩 에이전트는 프롬프트 구성을 단순 검색 문제로 다뤄, 파일과 컨텍스트를 계속 추가하며 모델이 알아서 처리하길 기대한다.

하지만 컨텍스트가 커지면 무관한 코드가 주의를 분산시키고, 창이 가득 차면 에이전트가 작업 도중 스스로 메모리를 압축하기 시작한다. 흔히 '망각'처럼 보이는 현상은 사실 컨텍스트 품질 저하일 뿐이다. 이 글은 프롬프트 구성을 컴파일러처럼 다뤄, 무엇을 유지하고 줄이고 버릴지 결정하는 방식을 제안한다.

WHY IT MATTERS

컨텍스트 창을 무작정 키우는 접근은 근본 해결책이 아니며, 코딩 에이전트의 성능 저하 원인을 재검토할 필요가 있음을 보여준다.

WHAT'S DIFFERENT

단순히 더 많은 파일을 검색해 컨텍스트에 채우는 기존 검색 기반 프롬프트 구성 방식과 달리, 무엇을 유지·축소·폐기할지 능동적으로 결정하는 컴파일러 방식을 제안한다.

★02에이전트를 워크플로우 안에 넣어라 — 고정 워크플로우와 적응형 에이전트를 결합한 하이브리드 LLM 패턴 제안Put the Agent Inside the Workflow✍️ 블로그 · towardsdatascience.com이 글은 미리 정의된 워크플로우와 적응형 에이전트 행동을 결합한 하이브리드 LLM 애플리케이션 패턴을 소개한다.

즉 전체 프로세스를 고정된 순서로 짜는 대신, 워크플로우 내부의 특정 단계를 에이전트가 자율적으로 처리하도록 배치하는 방식이다. 이를 통해 예측 가능성과 유연성을 동시에 확보하려는 접근을 제시한다.

WHY IT MATTERS

완전 자율 에이전트는 제어가 어렵고 고정 워크플로우는 유연성이 떨어지는 문제를 절충하는 실용적 설계 패턴이어서, 실제 LLM 애플리케이션 설계를 고민하는 개발자에게 참고가 된다.

WHAT'S DIFFERENT

완전 자율형 에이전트 아키텍처나 순수 고정 워크플로우 방식과 달리, 에이전트를 워크플로우 내부에 배치하는 절충적 구조를 제안한다.

WHY IT MATTERS

희소하고 불규칙한 감각 신호로부터 목표에 도달하는 탐색 전략은 로봇의 가스 누출 탐지나 자율 항법 알고리즘 설계에도 참고가 될 수 있는 문제다. 핀 머리 크기의 뇌로 복잡한 환경 신호를 처리하는 방식을 이해하면 작은 신경계의 계산 능력에 대한 통찰을 얻을 수 있다.
