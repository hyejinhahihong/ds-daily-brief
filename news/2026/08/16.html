★01Thought-Level Beam Search for ReasoningGambit, 사고 단위 빔서치로 LRM 추론 최적화 — HMMT-24 +6.7%p, 처리량 2배, 토큰 68.5% 절감📄 논문 · arxiv.org이 논문은 대형 추론 모델(LRM)의 테스트 타임 연산 배분 문제를 부분 추론 경로에 대한 제약된 자원 할당 문제로 정식화한다.

기존 병렬 샘플링은 경로를 독립적으로 다뤄 메모리 병목을 유발하고, 제거식 가지치기는 하드웨어 활용률을 떨어뜨려 출력 분포를 충분히 개선하지 못한다는 한계를 지적한다. 이를 해결하기 위해 저자들은 유망하지 않은 경로를 주기적으로 제거하고 우수한 접두 경로에서 즉시 분기하는 사고 단위 빔서치 알고리즘 Gambit을 제안하며, 은닉 상태를 탐지하는 경량 스코어러로 연산을 동적으로 집중시킨다. 여러 모델과 벤치마크 실험에서 Gambit은 기존 베이스라인을 일관되게 능가했다.

WHY IT MATTERS

테스트 타임 연산 확장이 LRM 성능의 핵심 동력인 상황에서, 얼마나 쓰느냐가 아니라 어디에 배분하느냐를 다루는 이 접근은 추론 비용 대비 성능 최적화 전략에 실질적 영향을 준다.

WHAT'S DIFFERENT

동일 하드웨어 제약에서 HMMT-24 +6.7%p, AIME-25 +3.3%p 정확도 향상, 2배 이상의 처리량, 표준 병렬 샘플링 대비 최대 68.5% 토큰 절감을 달성하며, 기존 병렬 샘플링과 제거식 가지치기 방식 모두를 능가한다.

★02Maglev: Sliding Recurrent MemoryMaglev, 슬라이딩 순환 메모리로 고정 크기 메모리 트랜스포머 구현 — 슬라이딩 윈도우·잠재 순환 베이스라인 능가📄 논문 · arxiv.orgMaglev는 고정 크기 메모리를 갖춘 순환 트랜스포머로, 슬라이딩 윈도우 어텐션을 일반화하면서도 학습 시 병렬화가 가능하다.

구조는 두 개의 결합된 모델로 구성되는데, 전체 어텐션(및 교차 배치된 슬라이딩 윈도우 어텐션)을 활용해 메모리 타깃 m'_t를 만드는 prefiller Q와, 슬라이딩 윈도우 어텐션과 순환 K/V 주입만으로 다음 토큰 예측용 메모리 m_t를 생성하는 디코더 P로 이루어진다. 학습 시에는 m_t와 m'_t를 정렬하는 메모리 일관성 손실을 사용하며, 추론 시에는 P만으로 동작한다. 실험 결과 검증 손실과 다운스트림 사전학습 벤치마크에서 슬라이딩 윈도우 및 잠재 순환 트랜스포머 베이스라인 대비 성능이 향상됐다. 또한 P와 Q 간 파라미터를 공유하면 성능 향상은 대부분 유지하면서 파라미터 메모리를 줄일 수 있다.

WHY IT MATTERS

긴 문맥 처리를 위한 고정 크기 메모리 구조는 추론 비용과 메모리 사용량을 줄이는 핵심 방향이며, 학습 병렬화를 유지하면서도 전체 히스토리 정보를 압축 전달하는 방식은 장기 문맥 모델링의 실용적 대안이 될 수 있다.

WHAT'S DIFFERENT

기존 슬라이딩 윈도우 어텐션이나 잠재 순환 트랜스포머 베이스라인과 달리, Maglev는 전체 어텐션 기반 prefiller Q가 만든 메모리 타깃에 슬라이딩 윈도우 기반 디코더 P를 정렬시키는 메모리 일관성 손실을 도입해 추론 시 P만으로 성능을 유지한다.

★01Sebastian Raschka, DistilBERT로 AI 텍스트 탐지기 직접 구축 — 검출 회피 SLM 학습용 검증기로도 활용Building an AI Text Detector From Scratch✍️ 블로그 · magazine.sebastianraschka.com이 글은 Substack의 AI 탐지 기능 출시를 계기로, 소규모 언어모델(SLM)의 활용 가능성을 보여주기 위해 AI 텍스트 탐지기를 직접 구현하는 튜토리얼이다.

텍스트가 AI 생성일 확률을 0~100점으로 반환하는 분류기를 DistilBERT를 파인튜닝하여 만들고, 이를 검증기(verifier)로 활용해 탐지를 회피하는 텍스트를 생성하도록 SLM을 학습시킨다. Pangram 모델과 유사한 방식을 채택했으며, 최종 결과물은 전체 텍스트 및 개별 청크 단위 점수를 보여주는 API와 로컬 브라우저 UI다. 저자는 AI 탐지기가 근본적으로 탐지 패턴과 이를 회피하는 LLM 간의 '고양이와 쥐' 게임이며 오탐(false positive) 가능성도 있음을 강조한다.

WHY IT MATTERS

수학·코드 중심 추론 모델을 넘어, 검증기 기반 LLM 응용을 텍스트 탐지라는 실용적 사례로 보여주는 교육적 가치가 있으며, 개인 글쓰기 교정 시 과도한 AI스러운 문체로 스팸 판정을 받는 실제 문제와도 맞닿아 있다.

WHAT'S DIFFERENT

범용 LLM 기반 문법 교정 도구와 달리, 이 프로젝트는 AI 생성 확률 점수를 검증 신호로 사용해 탐지를 회피하면서도 원문성을 유지하는 텍스트 생성 학습에 초점을 맞춘다.
