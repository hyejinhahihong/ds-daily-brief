02Echoverse: Deep, Evolving Environments for Training Computer-Use Agents at ScaleMS, Echoverse 공개 — 12개 합성 환경으로 9B 컴퓨터 사용 에이전트 정확도 36.5%→67.1%📄 논문 · arxiv.orgEchoverse는 사양을 컴퓨터 사용 에이전트가 실제로 조작·붕괴·재설정할 수 있는 상태 유지형 애플리케이션으로 컴파일하고, 과제를 애플리케이션 자체 데이터베이스로 채점하는 시스템이다.

채점된 각 롤아웃을 환경·과제·검증기 수정용과 모델 학습 신호용으로 두 번 활용하는 공동진화 루프를 도입했다. 12개 환경으로 학습한 9B 모델은 14개 평가 스플릿에서 36.5%에서 67.1%로 향상되어, 이를 가르친 훨씬 큰 프론티어 모델과 14포인트 차이로 좁혀졌다. 얕은 환경은 실제 사이트 정확도를 오히려 낮췄지만 깊은 환경은 최대 65.0%까지 높였고, 하나의 환경을 수정하는 것만으로 성능이 16.2%에서 38.5%로 상승했다. 동일한 환경은 강화학습에도 활용되어 검증기와 조밀한 단계별 판정을 결합한 보상이 held-out 점수를 58.8%에서 68.0%로 끌어올렸다.

WHY IT MATTERS

합성 환경 생성 파이프라인이 대량화되면서 병목이 '개수'에서 '내용의 질'로 옮겨간 상황에서, 행동적 깊이·실패 지점 타겟팅·모델과의 공진화라는 세 요소를 실증적으로 분리해 보여준 점이 중요하다. 로그인이 필요한 상태 유지형 실제 애플리케이션을 다루는 에이전트 훈련 데이터 확보 문제에 직접적인 해법을 제시한다.

WHAT'S DIFFERENT

기존의 대량 생성 위주 합성 환경 파이프라인과 달리, 단순히 환경 수를 늘리는 대신 깊이·실패 지점 정합성·모델과의 공진화라는 질적 요소가 성능을 좌우함을 보이고, 채점된 롤아웃을 환경 수정과 모델 학습 신호로 이중 활용하는 공동진화 루프를 도입했다.

WHY IT MATTERS

롱컨텍스트·에이전트 워크로드가 표준이 되어가는 상황에서 어텐션 설계가 추론 지연과 비용에 직결되므로, 모델 아키텍처 단계부터 하드웨어 실행 방식을 고려하는 접근이 실무적으로 중요해진다.

WHAT'S DIFFERENT

★01Apple, MoMo 공개 — 시공간 행동 토큰화로 로봇 조작의 '움직임 모드'를 조절 가능한 재사용 요소로 학습MoMo: Dial Motion Mode in Robot Manipulation with Spatiotemporal Action Tokenization✍️ 블로그 · machinelearning.apple.comMoMo는 로봇이 과제, 대상 물체, 상호작용 상황에 맞춰 동작이 펼쳐지는 방식 자체를 조절할 수 있는지 탐구하는 2단계 모방학습 프레임워크다.

먼저 시공간 행동 토크나이저로 동작을 표현하고, 이어서 과제 정보와 연속적인 '모션 모드' 조건을 입력받는 행동 복제(behavior-cloning) 트랜스포머를 학습시킨다. 6개의 실제 로봇 조작 과제에서 이 모션 모드 조건 값을 바꾸면 실행 양상이 일관되게 변화하는 것으로 나타났다. 즉, 실행 방식의 변화를 여러 과제에 걸쳐 재사용 가능한 행동 요소로 분리해 학습할 수 있음을 보인 것이다.

WHY IT MATTERS

동작의 정확성뿐 아니라 실행 스타일까지 제어할 수 있으면 하나의 정책으로 다양한 물체·환경에 유연하게 적응하는 로봇 시스템 설계가 가능해진다.

WHAT'S DIFFERENT

기존 모방학습이 과제별 고정된 동작 실행 방식을 암묵적으로 학습하는 것과 달리, MoMo는 연속적인 모션 모드 조건을 명시적으로 입력해 과제 전반에 걸쳐 재사용 가능한 실행 스타일 요소로 분리한다.

01Memory Efficient Tabular Foundation Models메모리 효율적 TabPFN — 모델 압축으로 메모리 최대 7.6배 절감, 성능 유지하며 배포 요구량 87% 감소📄 논문 · arxiv.org · ICML 2026TabPFN과 같은 Tabular Foundation Model은 인컨텍스트 표 데이터 학습에서 기존 방법을 능가하는 성능을 보이지만, 실제 배포 관점에서의 메모리 요구사항은 상대적으로 덜 연구되어 왔다.

이 논문은 이러한 모델의 메모리 사용량을 분석하고, 모델 압축 기법을 적용해 성능을 유지하면서 메모리를 최대 7.6배 줄일 수 있음을 보인다. 이는 배포에 필요한 리소스를 약 87% 감소시키는 효과에 해당한다. 저자들은 이 결과가 실무자들이 이런 모델을 효율적으로 배포하는 데 도움이 될 것이라고 밝힌다.

WHY IT MATTERS

고성능 표 데이터 파운데이션 모델도 메모리 제약 때문에 실제 서비스 환경에 적용하기 어려운 경우가 많은데, 이 연구는 성능 손실 없이 배포 장벽을 낮추는 실용적 방향을 제시한다.

WHAT'S DIFFERENT

기존 TabPFN 등 Tabular Foundation Model 연구가 성능 자체에 집중했던 것과 달리, 이 논문은 배포 시 메모리 효율성이라는 실무적 측면에 초점을 맞춘다.

02CORE: In-Context Reconstruction for Unified Tabular Anomaly DetectionCORE 제안 — 재구성 기반 in-context 학습으로 이질적 표 데이터에서 통합 이상탐지 수행📄 논문 · arxiv.org이 논문은 여러 서로 다른 표 데이터셋에서 하나의 모델로 이상치를 탐지하는 '통합 TAD' 문제를 다룬다.

기존 방법은 거리 기반으로 통합 피처를 구성해 원본 피처의 의미를 훼손하고, 이진 분류로 문제를 정식화해 다양한 이상 패턴을 놓치거나 대표성 없는 합성 이상치에 오도되는 한계가 있었다. 저자들은 CORE를 제안해 탈상관 피처 정렬 모듈로 이질적 피처를 의미를 유지한 채 통합 표현 공간으로 정렬한다. 동시에 통합 TAD를 in-context 재구성 문제로 재정식화해, 문맥상 정상 샘플을 활용해 각 샘플을 재구성하고 그 오차로 정상성 이탈 정도를 판단함으로써 라벨이나 합성 이상치 없이도 미지 데이터셋에 대한 탐지가 가능하다.

WHY IT MATTERS

실무에서는 데이터셋마다 별도 이상탐지 모델을 학습해야 하는 비용이 크므로, 라벨이나 합성 이상치 없이 다양한 표 데이터에 적용 가능한 일반화 모델은 실제 배포 효율성을 크게 높일 수 있다.

WHAT'S DIFFERENT

기존의 거리 기반 통합 피처 구성 및 이진 분류 기반 정식화 방법 대비, CORE는 피처 의미를 보존하는 정렬과 라벨 없는 in-context 재구성으로 접근한다는 점이 다르다.

03EvoCause: LLM-Guided Evolution of Causal Graphs for Root Cause AnalysisEvoCause, LLM으로 인과 그래프 진화시켜 근본원인분석 — PC 대비 Node F1 11.59%p 향상📄 논문 · arxiv.orgEvoCause는 통신·클라우드 시스템의 경보 계단현상에서 근본 원인을 찾는 근본원인분석(RCA) 방법으로, 관측 로그에서 학습한 인과 그래프를 전문가의 과거 사고 진단 라벨로 개선한다.

전문가 라벨은 어떤 알람이 근원 노드여야 하는지만 알려주고 구체적인 그래프 수정 방법은 지정하지 않는데, EvoCause는 LLM으로 의미상 타당한 그래프 편집을 제안하고 결정론적 코드로 노드 정체성과 비순환성을 검증해 라벨 정렬 집합에서 최적 그래프를 선택한다. 테스트 시에는 정제된 그래프만으로 LLM 호출 없이 투명한 예측을 수행한다. 연구진은 실제 통신망에서 수집한 485,681건의 경보 이벤트, 194개 알람 유형, 5,621개 리소스로 구성된 벤치마크 TeleRCA도 공개했다. 합성 데이터에서 PC 알고리즘으로 초기화한 EvoCause는 정제 없는 PC 대비 Node F1을 11.59%p 향상시켰고, Case EM과 Graph F1도 각각 9.40, 4.59%p 개선했으며 nSHD는 0.2379 감소시켰다.

WHY IT MATTERS

고정된 인과 그래프에 전문가 피드백을 반복 반영할 수 있게 함으로써, RCA 시스템이 과거 사고 진단 지식을 지속적으로 흡수해 정확도를 높일 수 있는 실용적 경로를 제시한다.

WHAT'S DIFFERENT

기존에는 관측 로그로 학습한 인과 그래프가 고정되어 전문가의 과거 진단 정보를 반영하지 못했지만, EvoCause는 LLM 기반 그래프 편집 제안과 결정론적 검증을 결합해 전문가 라벨에 맞게 그래프를 지속적으로 개선한다.
