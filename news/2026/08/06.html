Supervisor 에이전트와 Education, Matching이라는 두 전문 워커 에이전트로 구성되며, LangGraph와 Model Context Protocol(MCP)로 조율된다. 모든 에이전트는 Amazon ECS와 AWS Fargate 위 컨테이너 서비스로 실행되고, 사용자 입력과 모델 출력은 Amazon Bedrock Guardrails를 통해 콘텐츠 필터링과 PII 마스킹, 프롬프트 위협 탐지를 거친다. 여기에 LLM 기반 안전 분류기가 병렬로 대화 정책을 강제해 지연 없이 이중 안전장치를 제공한다.

WHY IT MATTERS

WHAT'S DIFFERENT

단순 FAQ 챗봇에 머무는 업계 관행과 달리, Supervisor-Worker 구조로 교육과 매칭을 분리해 복잡한 질의 응답과 대출 매칭까지 처리하도록 설계했다는 점이 차이다. 또한 Amazon Bedrock AgentCore가 정식 출시되기 전에 이미 운영 중이었기 때문에 Amazon ECS/Fargate를 기반으로 구축했다.

01RestoreKV: Recovering Full-Cache Behavior Under Aggressive Query-Agnostic KV Cache EvictionRestoreKV, 쿼리 무관 KV 캐시 압축 손실 복원 — Qwen3-4B에서 KVzip 정확도 38.2→73.2 회복📄 논문 · arxiv.orgRestoreKV는 컨텍스트를 한 번 압축해 여러 쿼리에 재사용하는 쿼리 무관 KV 캐시 제거 방식에서, 기존 방법들이 어떤 KV를 남길지에 집중한 것과 달리 손실된 정보를 학습으로 복원하는 방식을 추가한다.

프리필 후 소수의 복원 토큰이 LoRA 어댑터를 통해 전체 KV 캐시에 단 한 번 어텐션하여 컨텍스트 조건부 복원 캐시를 생성하며, 이후 쿼리·디코딩에서는 어댑터를 비활성화한다. 전체 파라미터의 0.4%만 학습하는 파라미터 효율적 자기증류 방식으로, 별도의 태스크별 튜닝 없이 4개 백본과 4개 장문맥 벤치마크에서 압축으로 인한 성능 저하를 크게 줄였다. Qwen3-4B 기준 5% 예산에서 RULER-4K의 KVzip 점수를 38.2에서 73.2로 끌어올렸고, KVzip+에 적용 시 16배 압축에서 86.4의 RULER 정확도를 달성하면서 캐시 구축 오버헤드는 0.5% 미만에 불과했다.

WHY IT MATTERS

장문맥 처리 시 메모리 제약으로 KV 캐시를 공격적으로 압축해야 하는 실제 서빙 환경에서, 기존 선택 기반 압축 방식의 근본적 한계를 보완할 실용적 해법이 될 수 있다.

WHAT'S DIFFERENT

기존 KV 제거 방법들이 어떤 원본 KV 쌍을 남길지 선택하는 데만 집중한 것과 달리, RestoreKV는 동일한 예산 내에서 학습된 복원 메커니즘을 추가로 결합해 KVzip 등 기존 5개 제거 방법 위에 얹어 성능을 향상시킨다.

01Apple, 이미지 생성용 Diffusion Transformer의 '이상치 토큰' 문제 분석 — RAE-DiT 인코더·디노이저 모두에서 발견Taming Outlier Tokens in Diffusion Transformers✍️ 블로그 · machinelearning.apple.com이 연구는 이미지 생성용 Diffusion Transformer(DiT)에서 나타나는 이상치 토큰 현상을 다룬다.

기존 Vision Transformer 연구에서 국소 정보는 적지만 과도한 어텐션을 끌어모으는 소수의 고노름 토큰이 존재함이 알려졌는데, 생성 모델에서의 역할은 충분히 조사되지 않았다. 저자들은 이 현상이 최신 Representation Autoencoder(RAE)-DiT 파이프라인의 인코더와 디노이저 양쪽 모두에서 나타남을 보였다. 사전학습된 ViT 인코더는 이상치 표현을 생성하며, DiT 자체도 특히 중간 층에서 내부 이상치 토큰을 발달시킬 수 있다.

WHY IT MATTERS

이상치 토큰은 어텐션 분포를 왜곡해 모델 해석이나 경량화, 양자화 작업에 방해가 될 수 있어, 생성 모델 아키텍처를 다루는 연구자와 엔지니어에게 실질적인 참고가 된다.

WHAT'S DIFFERENT

기존 Vision Transformer의 이상치 토큰 연구가 판별 모델에 국한됐던 것과 달리, 이 연구는 생성 모델인 RAE-DiT 파이프라인의 인코더와 디노이저 모두에서 해당 현상을 확인했다는 점이 다르다.

01Traceable Multi-Agent System for Knowledge-Based ForecastingTraceMAS, 원유가 예측서 인과루프로 멀티에이전트 예측 근거를 투명하게 추적하는 데모 시스템 제시📄 논문 · arxiv.org · KDD 2026TraceMAS는 문서 해석, 데이터 검색, 코드 생성, 모델 수정을 자율적으로 수행하는 멀티에이전트 예측 시스템의 의사결정 과정을 추적 가능하게 만든 인터랙티브 데모다.

도메인 문서에서 추출한 핵심 요인과 인과관계를 담은 Ideal Causal Loop Diagram과, 이를 내부 변수·외부 데이터·대리 지표에 연결한 Data-Grounded CLD 두 가지 인과루프 표현을 중심으로 에이전트 출력을 조직화한다. Data-Grounded CLD는 피처 구성과 모델 설계를 안내하면서 텍스트 근거, 데이터 선택, 모델 수정 간의 연결을 보존한다. 원유가 예측을 사례로, 사용자는 예측 반복 과정 비교, 에이전트 단계별 수정 검토, 인과맵 탐색, 피처-데이터 매핑과 모델 구조 검토, 시나리오 예측과 시장 내러티브 연결이 가능하다.

WHY IT MATTERS

자율 에이전트가 예측 파이프라인을 스스로 수정하는 방식이 확산될수록, 예측이 왜 바뀌었고 어떤 근거가 반영됐는지 검증할 수단이 없으면 실무 신뢰도가 떨어진다는 문제를 다룬다.

WHAT'S DIFFERENT

기존 자율 예측 에이전트가 유연성을 위해 내부 의사결정 과정을 불투명하게 두는 것과 달리, 두 층위의 인과루프 다이어그램으로 근거-데이터-모델 수정 간 연결을 명시적으로 보존해 검증 가능성을 확보한다.

여기에 O'Reilly Expert MCP 서버를 추가해 같은 질문을 다시 던지자, Google SRE의 운영 toil 개념을 인용해 문제가 인력 부족이 아니라 구조적 문제(약 67%의 toil 비율)라고 진단하고 toil 감사·감축 목표 설정 등 구체적 조치를 제안했다. 이 사례를 바탕으로 조직 인텔리전스 시스템 구축의 4단계 방법론(정보 계층 매핑, LLM-MCP 연결과 스킬 파일 작성, 전문가 리뷰 레이어 추가, 휴먼인더루프 검토)을 제시한다. 저자는 이 접근이 엔지니어링뿐 아니라 정보가 여러 시스템에 흩어져 있고 종합적 판단이 필요한 모든 조직 기능에 일반화될 수 있다고 설명한다.

WHY IT MATTERS

AI 에이전트가 데이터를 그저 요약하는 수준을 넘어 확립된 전문 프레임워크에 근거해 판단 가능한 근거를 제시하도록 만드는 방법을 보여줘, 조직 의사결정에 AI를 적용하려는 실무자에게 구체적인 설계 아이디어를 제공한다.

WHAT'S DIFFERENT

기존의 내부 시스템 연결 AI 에이전트가 헤드카운트·티켓 백로그 등 데이터 중심 요약만 제공했던 것과 달리, 여기에 전문가 지식 기반의 MCP 레이어를 추가해 SRE 프레임워크 같은 확립된 이론에 근거한 구조적 진단과 실행 가능한 권고를 도출한다는 점이 다르다.

★01Meta, 광고 랭킹용 멀티스테이지 시퀀스 모델 공개 — 인스타그램 전환 **6%**, 페이스북 전환 3%·클릭 3.5% 개선From User Sequences to Scaling Laws: A Multi-Stage Architecture for Meta’s Ads Ranking✍️ 블로그 · engineering.fb.comMeta가 광고 추천 시스템에 LLM 스타일 스케일링 법칙을 적용하기 위한 두 가지 아키텍처를 소개했다.

첫째는 무거운 오프라인 사용자 모델링과 가벼운 온라인 랭킹 작업을 분리하는 멀티스테이지 시퀀스 모델로, 긴 사용자 히스토리를 비동기 처리해 캐시된 임베딩을 만들고 이를 실시간 광고 신호와 결합해 랭킹을 산출한다. 둘째는 밀집 토큰화와 타겟 인지 어텐션 기반 학습 기법으로, 특징 상호작용을 데이터로부터 직접 학습한다. 이러한 개선들과 다른 모델 혁신이 결합되어 인스타그램 전환 6%, 페이스북 전환 3%, 페이스북 광고 클릭 3.5%의 누적 개선을 달성했다. 이 통합 플랫폼은 Meta의 생성형 광고 추천 모델(GEM)의 핵심 구성요소다.

WHY IT MATTERS

밀리초 단위로 수백만 개 후보를 처리해야 하는 대규모 광고 랭킹 시스템에서 시퀀스 길이와 모델 규모를 서빙 비용 증가 없이 확장할 수 있는 방법을 제시한다는 점에서 산업적으로 중요하다.

WHAT'S DIFFERENT

기존 하이브리드 방식은 사용자 이벤트 시퀀스 처리 모델과 스파스 특징 처리 모델을 별도로 운용해 손실 있는 지식 전달, 수동 특징 엔지니어링 의존, 랭킹·시퀀스 모델 간 간섭으로 인한 확장 한계가 있었으나, 이 접근은 오프라인/온라인 단계를 분리하고 밀집 토큰화·타겟 인지 어텐션을 도입해 이러한 병목을 해소했다.

WHY IT MATTERS

온프레미스 시스템과 클라우드를 연결하는 하이브리드 아키텍처로 엔터프라이즈급 거버넌스와 보안을 유지하면서 AI 에이전트를 확장하려는 기업들에게 실질적인 참고 사례가 된다. 정형화된 규칙 기반 자동화의 한계를 넘어 MCP 기반 실시간 API 접근으로 맥락 이해형 에이전트를 구현한 점이 핵심이다.

WHAT'S DIFFERENT

기존의 스크립팅, 정적 워크플로, 규칙 기반 의사결정 트리 방식 자동화 대비, MCP로 실시간 API를 조회해 상황을 해석하는 지능형 에이전트로 전환한 것이 차이점이다.
