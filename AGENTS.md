
# Repository Safety Rules



- Never make commits directly on `main`.

- Never merge pull requests.

- Never deploy or run production-affecting commands.

- Before editing code, create and use a new descriptive branch from the current `main`.

- Keep every code change, commit, and pull request limited to this repository.

- Before committing, run relevant tests and report their actual result.

- Before creating a pull request, show the changed files and a concise summary.

- Ask for confirmation before any destructive operation, dependency upgrade, credential change, or external-service change.
