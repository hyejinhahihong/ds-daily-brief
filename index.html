Polymarket 이벤트 1,568개와 날짜가 기록된 뉴스 기사 1,880만 건을 시간 기준으로 학습·평가 구간으로 분리해 구성했다. 12개 모델을 평가한 결과 조사 도구를 쓰면 모든 모델의 Brier 점수가 개선되고, 새 증거가 많이 기록되는 시점일수록 예측 개선폭이 컸다. 다만 모든 모델이 Brier 점수와 정확도 모두에서 역사적 시장 예측을 넘지 못했으며, 날짜 간 이어지는 belief notebook은 조사 비용은 줄이지만 예측 품질을 일관되게 높이진 않았다. 지도학습 미세조정을 예시로, 상호작용 궤적과 결과 피드백을 통한 에이전트 학습도 지원한다.

WHY IT MATTERS

실제 사건 발생을 기다리지 않고도 반복 평가와 학습 데이터 수집이 가능해, LLM 예측 에이전트 연구의 재현성과 속도를 높일 수 있는 벤치마크 인프라를 제공한다.

01SGA: Uncertainty Quantification for Multi-Step Forecasting in Time Series Foundation ModelsSGA 기법, TSFM 다단계 예측 불확실성 정량화 — 11개 모델·27개 데이터셋서 최고 성능📄 논문 · arxiv.org시계열 파운데이션 모델(TSFM)은 다단계 예측에서 뛰어난 성능을 보이지만, 각 시점마다 갈라지는 예측 분기들이 서로 다른 정확도를 보이며 신뢰성 문제를 일으킨다.

이 논문은 이런 불확실성을 정량화하기 위해 Slicing-Graphing-Alignment(SGA) 방법을 제안한다. SGA는 가능한 모든 예측 분기의 위상 구조를 방향성 비순환 그래프(DAG)로 표현하고, 그래프 복잡도와 TSFM 고유의 확률성을 결합해 불확실성을 측정한다. 11개 TSFM과 27개 데이터셋 실험에서 SGA는 예측 오차를 불확실성 추정치로 순위화할 때 가장 우수한 성능을 보였고, 모델 규모가 클수록 다단계 예측의 불확실성 추정치가 낮아지는 새로운 스케일링 법칙도 발견되었다.

WHY IT MATTERS

다단계 시계열 예측의 신뢰도를 사전에 가늠할 수 있다면 실제 배포 시 위험한 예측 분기를 걸러내거나 경고할 수 있어, TSFM 활용의 실용성을 높이는 데 중요하다.

WHAT'S DIFFERENT

기존 불확실성 정량화 방법 대비 더 폭넓고 정밀한 샘플링 커버리지를 갖추며, 위상 정보와 모델 고유 확률성을 결합한 근본적으로 다른 정량화 메커니즘을 사용한다.

01Netflix, EMR Spark 워크로드에 클라우드 자격증명 대신 내부 Metatron 인증서 부여하는 attestation 구조 공개Trading a Cloud Identity for Your Own: Workload Attestation on Managed Compute✍️ 블로그 · netflixtechblog.comNetflix는 관리형 컴퓨팅(EMR) 위에서 실행되는 Spark 워크로드가 처음엔 AWS 실행 역할만 가진 채 시작하지만, 내부 서비스 간 인증에 필요한 첫급 내부 신원(Metatron X.509 인증서)을 얻도록 하는 방법을 설명한다.

핵심은 각 Data Project 신원과 전용 IAM 역할을 1:1로 매핑해 두고, 이 매핑을 근거로 '이 프로세스는 역할 R로 실행 중'이라는 AWS의 진술을 '이 프로세스는 워크로드 W'라는 내부 진술로 번역하는 것이다. 계정당 IAM 역할 수 제한 문제는 데이터 프로젝트 역할을 소수의 전용 계정에 결정적으로 샤딩해 해결했다. 구현은 컨트롤 플레인, Data Project 서비스, Identity 서비스, Spark 플러그인, AWS STS 다섯 개 컴포넌트로 구성되며, 컨트롤 플레인이 서명된 워크로드 메타데이터를 만들어 작업을 제출하고 STS가 공증 역할을 한다.

WHY IT MATTERS

관리형 컴퓨팅 환경에서는 클라우드가 부여하는 신원과 조직 내부 신원 체계가 분리되어 있어, 테이블 수준 접근 제어나 감사 같은 내부 정책을 그대로 적용하기 어렵다는 실질적 문제를 다룬다. Spark나 EMR에 국한되지 않는 일반적인 워크로드 attestation 패턴이라, 다른 관리형 서비스에서도 참고할 수 있는 설계다.

WHAT'S DIFFERENT

기존에는 클라우드 IAM 역할과 내부 인증 시스템(Metatron)이 병행 운영되며 서로 신뢰를 연결할 방법이 없었으나, 이 설계는 Data Project 신원과 IAM 역할의 명시적 1:1 매핑을 신뢰의 근거로 삼아 두 시스템을 연결한다는 점이 다르다.

후처리 관점에서 선택과 감사 기록을 거쳐도 차분 프라이버시 보장이 유지되며, 선택기 입력이 공개적이거나 독립적, 혹은 별도로 프라이버시 계산될 때만 종단 간 보장이 성립하고 원시 상태나 후보 정보를 고정하면 조건부 보장만 얻는다. 또한 점수 유도 목적함수의 변동이 가장 작은 그리디 결정 마진의 절반 이하이면 정렬된 슬레이트가 변하지 않는다는 로그 마진 인증서를 도출했다. 고정 마진 테스트에서 독립 잡음 기준 기울기 -1/4에 대비해 실측 기울기 -0.220(95% CI [-0.231, -0.210])의 거의 선형적인 지수 스케일링을 확인했다. OULAD, MovieLens-25M, Amazon Musical Instruments 실험에서 앵커 가중치가 클수록 점수 잡음으로 인한 순위 변동(churn)이 줄었다.

WHY IT MATTERS

프라이버시를 적용한 추천 시스템에서 잡음이 최종 순위를 얼마나 흔드는지 정량적으로 검증할 수 있는 인증 가능한 안정성 메커니즘을 제공한다는 점에서, 실제 서비스 배포 시 프라이버시-성능 트레이드오프를 설계할 근거가 된다.

WHAT'S DIFFERENT

보편적 유틸리티 주장을 하는 기존 접근과 달리, 이 연구는 프라이버시 범위 계약과 순위 불변을 보장하는 로그 마진 인증서라는 특정 조건 하의 검증 가능한 기여로 스스로를 한정한다.
