01CAPTURE: Disentangling Preference Drift from Memory Poisoning in Personalized LLM AgentsCAPTURE, 개인화 LLM 에이전트 메모리 오염 방지 — 승률 71.5%, 오염 성공률 11.5%로 억제📄 논문 · arxiv.org · ICLR 2027개인화 언어 에이전트는 장기 메모리로 사용자에 적응하지만, 이 메모리가 새로운 정보와 충돌할 때 진짜 선호 변화와 임시적 맥락 변화, 모호성, 악의적 메모리 오염을 구분해야 하는 문제가 있다.

저자들은 이를 잠재 사용자 상태에 대한 연속시간 부분관측 결정과정으로 정식화하고, 최신성과 출처만 보는 규칙으로는 부족함을 보인다. CAPTURE는 신경망 미분방정식 기반 신념 추적기, 다중 시간축 메모리 원장, 불확실성 기반 확인 요청, 인용된 메모리에 대한 반사실 검증을 결합한다. 96명 사용자의 480개 held-out 에피소드에서 CAPTURE는 71.5% 승률을 기록했으며, 동일하게 감독학습된 베이스라인(69.3%)과 최강 휴리스틱 베이스라인(66.1%)을 앞섰다. 고정 정책 공격의 성공률을 11.5%로 제한하면서도 진짜 선호 업데이트의 83.5%는 수용했지만, 공개된 가중치에 접근 가능한 적응형 공격자에게는 성공률이 24.7%까지 올라 적응성-보안성 간 트레이드오프가 드러났다.

WHY IT MATTERS

메모리 증강 LLM 에이전트가 확산되면서 저장된 선호를 조작하는 메모리 오염 공격이 실질적 위협이 되는데, 이는 개인화 시스템 설계 시 보안을 정면으로 고려해야 함을 시사한다.

WHAT'S DIFFERENT

최신성과 출처 기반의 기존 휴리스틱 규칙 대비, 선호의 진위 자체를 명시적으로 모델링해 개인화와 견고성을 동시에 개선한다는 점이 다르다.

01XMerge: Cross-Axis Selection and Reconstructive Layer Merging for LLM Depth CompressionXMerge, LLM 레이어 제거 압축법 제안 — k=4 최대 압축서 7개 백본 중 6개서 CORE·MMLU 1위📄 논문 · arxiv.org · NeurIPS 2026XMerge는 트랜스포머 레이어 전체를 제거하는 깊이 압축 기법으로, 크기·각도 변화가 작은 블록을 고르는 cross-axis selection과 인접 블록을 재학습해 원래 두 블록 출력을 재현하는 local boundary reconstruction 두 요소로 구성된다.

태스크 라벨이나 종단간 파인튜닝 없이 아키텍처 변경이나 추가 추론 파라미터 없이 작동한다. Llama·Qwen 7개 백본(0.5B~8B)과 5개 기존 베이스라인, 3단계 레이어 축소 수준에서 평가한 결과, 가장 공격적인 제거(k=4)에서 CORE와 MMLU 모두 7개 중 6개 백본에서 1위를 기록했다. 14개 (모델, 환경) 조합 전체에서 성능이 붕괴하지 않은 유일한 방법이었으며, ablation 결과 local reconstruction이 성능 향상의 대부분을 담당했다.

WHY IT MATTERS

레이어 제거 기반 압축은 표준 서빙 구조를 유지할 수 있지만 모델별로 품질 손실이 예측 불가능했는데, 이를 안정적으로 줄이는 방법은 실제 추론 비용 절감에 직결된다.

WHAT'S DIFFERENT

기존 5개 공개 베이스라인 대비 가장 공격적인 압축 수준(k=4)에서 우위가 가장 크고, 성능 붕괴 없이 zero-shot·in-context 환경 모두에서 top-2를 유지한 점이 차별점이다.

02FlashKAN: B-Spline KANs via Truncated Power FormFlashKAN, B-스플라인 KAN 순전파를 truncated power form으로 재구성해 GPU 커널 하나로 압축📄 논문 · arxiv.org · ICLR 2027KAN은 노드가 아닌 엣지에 학습 가능한 B-스플라인 활성화를 두는데, 기존 Cox-de Boor 재귀 방식은 차수 k의 스플라인마다 k번의 순차 연산이 필요해 순전파 시간의 90% 이상을 차지한다.

FlashKAN은 이 재귀 대신 균일 3차 B-스플라인을 이동된 매듭 위치에서의 5개 (x)_+^3 항으로 표현하는 근사이론의 고전적 결과인 truncated power form을 사용한다. torch.compile로 융합된 구현을 통해 재귀, 스팬 탐색, scatter-gather 연산을 모두 제거하고 단일 GPU 커널로 압축했으며, 정규화된 입력을 [0, k+1]로 클램핑하는 bounded-coordinate 안정화 기법으로 파괴적 상쇄 문제를 방지했다. pip install flashkan으로 설치 가능한 오픈소스 패키지로, 기존 KAN 레이어의 드롭인 대체품으로 제공된다.

WHY IT MATTERS

KAN의 실용성을 가로막던 핵심 병목인 순전파 연산 비용을 근본적으로 재설계해 해결한 사례로, KAN 기반 모델의 실제 배포 가능성을 높인다.

WHAT'S DIFFERENT

기존 Cox-de Boor 재귀 방식이 파괴적 상쇄 문제 때문에 채택되어 온 것과 달리, FlashKAN은 truncated power form과 bounded-coordinate 클램핑으로 재귀 없이도 수치 안정성을 확보했다.

★02Do Tabular Foundation Models Know Physics? Contamination, Units, and the Deterministic Limit표 기반 파운데이션 모델, 물리를 아는가 — TabPFN-3 등 4종, 316개 물리 방정식서 6개 베이스라인 압도하지만 단위·무결정성 못 다뤄📄 논문 · arxiv.org · NeurIPS 2026연구진은 TabPFN-3, TabICLv2, TabDPT, Real-TabPFN-2.5 등 4개 표 기반 파운데이션 모델(TFM)을 6개 베이스라인과 함께 316개 물리 방정식에서 샘플링한 데이터셋으로, 도메인 내외 조건에서 평가했다.

TFM은 별도 튜닝 없이도, 그리고 튜닝 후에도 베이스라인을 압도하는 성능을 보였다. 그러나 이 모델들의 사전분포(prior)는 잡음이 없는 결정론적 메커니즘도, 물리 단위도 표현하지 못한다는 것을 보였다. 이 때문에 TFM은 물리 현상을 보간(interpolate)할 수는 있지만 아직 진정한 물리 모델로 작동하지는 못한다.

WHY IT MATTERS

TFM이 베이지안 사전분포를 통해 물리 법칙 비슷한 패턴을 암묵적으로 학습했는지는 이 모델들을 과학 데이터에 적용할 때 신뢰성의 근본 한계를 가른다. 단위와 결정론적 메커니즘을 표현하지 못한다는 사실은 TFM을 실제 물리 모델링에 쓸 때 주의해야 할 지점을 명확히 짚어준다.

WHAT'S DIFFERENT

기존 연구가 TFM의 표 데이터 예측 성능 자체를 검증한 것과 달리, 이 논문은 TFM의 베이지안 사전분포가 물리적 단위와 무잡음 결정론적 메커니즘을 표현할 수 있는지를 직접 검증했다는 점에서 다르다.

01COSTA: Covariance-Optimized Design and Causal Inference under Network-Temporal InterferenceCOSTA: 네트워크-시간적 간섭 하 실험설계, 공분산 최적화로 RMSE 대폭 감소📄 논문 · arxiv.org이 논문은 시간에 따라 관찰되는 네트워크 실험에서 발생하는 스필오버, 시간적 이월 효과, 설계로 인한 의존성을 다루기 위해 COSTA라는 결합 베르누이 설계를 제안한다.

처리 마진과 비음 선형 네트워크-시간 노출 모델 하에서 Horvitz-Thompson 편향이 할당 절단의 음의 기대 가중치와 정확히 일치함을 보이고, 이를 바탕으로 할당 공분산을 직접 최적화하는 MSE 상한을 도출한다. 확장을 위해 네트워크와 시간 노출 연산자를 모사하면서도 유효한 베르누이 마진을 유지하는 임계 가우시안 크로네커 파라미터화를 도입한다. 또한 설계된 처리 의존성과 간섭 유발 결과 의존성의 결합 효과에 대한 추론 이론을 개발하고, RetailRocket과 MovieLens 반합성 실험을 통해 RMSE의 상당한 감소와 잘 보정된 설계 중심 구간을 확인했다.

WHY IT MATTERS

네트워크 효과와 시간적 이월이 동시에 존재하는 실험(예: 마켓플레이스, 추천시스템 A/B 테스트)에서 편향과 분산을 함께 통제할 수 있는 실질적 설계 도구를 제공한다는 점에서 실무 인과추론 연구자에게 중요하다.

WHAT'S DIFFERENT

기존의 개별 처리 마진만 고정하는 무작위 배정 방식과 달리, COSTA는 할당 공분산 자체를 직접 최적화하여 네트워크-시간적 노출 구조에 맞춘 편향-분산 트레이드오프를 설계 단계에서 조절한다.

02GenCAR: Generative Counterfactual Alignment with Risk-Controlled Selection for Out-of-Distribution RecommendationGenCAR, 분포외 추천서 반사실적 후보 생성하며 proxy-label FDR까지 통제 — 벤치마크 전반 회복률 향상📄 논문 · arxiv.org이 연구는 분포 변화(OOD) 상황에서 추천 후보 집합의 proxy-label 허위 발견율(FDR)을 통제하지 못하는 기존 방법의 한계를 지적하며, 이를 α-Valid Counterfactual Recommendation(α-VCR) 문제로 정식화한다.

제안하는 GenCAR은 안정적 선호 표현은 고정하고 환경 요인에만 개입해 반사실적 후보를 생성하며, 오프라인 대형언어모델의 제안을 선호 앵커와 신뢰 반경 필터링으로 검증한다. 이후 conformal p-value 기반 Benjamini-Hochberg 선택으로 후보 집합을 걸러낸다. 이론적으로는 조건부 반사실적 근사 오차의 상한을 제시하고, 교환가능성과 양의 회귀 의존성 하에서 유한 샘플 기반 FDR 통제를 증명했으며, 임의의 의존성에서는 Benjamini-Yekutieli 보장을 제공한다. 다양한 벤치마크 실험에서 실제 허위 발견 비율을 검증하고 OOD 후보 회복 성능이 일관되게 향상됨을 보였다.

WHY IT MATTERS

추천 시스템이 분포 변화 상황에서 위험을 통제하며 후보를 늘리는 것은 실서비스 신뢰도와 직결되는 문제로, 통계적 보장 없이 반사실적 후보를 확장하면 잘못된 추천 노출 위험이 커진다.

WHAT'S DIFFERENT

기존 OOD 추천 방법들이 랭킹 개선이나 반사실적 후보 구성에 집중하며 proxy-label FDR을 통제하지 않은 것과 달리, GenCAR은 conformal p-value와 Benjamini-Hochberg/Yekutieli 절차를 결합해 분포 무관하게 FDR을 보장한다.

01Meta, ZippyDB 프록시 ZGateway 도입 — 커넥션 폭증·재부팅 루프 장애 원천 차단ZGateway: Learnings from Putting a Proxy in Front of ZippyDB✍️ 블로그 · engineering.fb.comMeta는 초당 수십억 건을 처리하는 키밸류 스토어 ZippyDB 앞에 ZGateway라는 프록시를 도입해 클라이언트 트래픽을 통합했다.

기존에는 백만 대 이상의 클라이언트가 수십만 대의 DB 호스트에 직접 연결해 다대다 TLS 커넥션 메시가 형성됐고, 클라이언트가 재시작하거나 배포가 롤아웃될 때마다 커넥션 재연결 폭주가 발생해 파일 디스크립터 고갈과 OOM으로 호스트가 크래시하는 사례가 있었다. ZGateway는 이 메시를 두 개의 제한된 홉으로 축소하고, 어드미션 컨트롤·로드밸런싱·리전 간 복원력·운영 기능을 한 곳에서 관리 가능하게 했다. 실제로 라우팅 버그로 모든 클라이언트가 샤드별 커넥션을 열어 파일 디스크립터 한계를 넘고 재부팅 루프에 빠진 사건도 ZGateway가 있으면 프록시 계층에서 차단할 수 있다고 설명한다.

WHY IT MATTERS

수백만 대 규모의 이질적 클라이언트 플릿을 직접 제어할 수 없는 상황에서, 프록시 계층은 백엔드 운영 팀이 커넥션 풀링·재시도·라우팅 같은 공통 로직을 한 곳에서 안전하게 개선할 수 있는 통제점을 제공한다는 점에서 대규모 분산 시스템 설계자에게 참고가 된다.

WHAT'S DIFFERENT

클라이언트가 각자 커넥션 풀링과 장애 복구를 관리하던 직접 접근 방식 대비, ZGateway는 프록시가 다대다 커넥션 메시를 두 개의 제한된 홉으로 collapse시켜 클라이언트 확장과 DB 통합이 서로 다른 속도로 진행되어도 결합을 끊어낸다.

02An Empirical Study on Zero-Data Bootstrapping for Conversational Recommender Systems대화 데이터 없이 CRS 구축 — 리뷰·메타데이터로 합성 대화 생성, 실증 연구로 효과 입증📄 논문 · arxiv.org이 연구는 대화형 추천시스템(CRS)을 도메인 대화 데이터 없이 구축하는 방법을 실증적으로 분석한다.

아이템 리뷰, 메타데이터, 사용자-아이템 상호작용 등 비대화 신호로부터 합성 대화 학습 데이터를 생성하고, Jensen-Shannon 다양성과 Fisher information 두 가지 정보이론적 선택 전략을 도메인, 모델 구조, 데이터셋, 파인튜닝 방식 전반에서 비교했다. 결과적으로 도메인 기반 합성 데이터가 제로샷 프롬프팅과 단순 합성 기법을 일관되게 능가했으며, 능동 선택 전략이 무작위 샘플링보다 데이터 효율이 높았다. 메타데이터와 협업 필터링 신호 모두 선택 품질을 높였고, 저자원 환경에서는 합성 데이터가 희소한 실제 대화 데이터를 보완하거나 대체할 수 있었다.

WHY IT MATTERS

신규 도메인마다 비용이 큰 대화 데이터를 수집하지 않고도 CRS를 구축할 수 있는 실용적 경로를 제시한다는 점에서, 데이터 확보가 어려운 산업 현장의 추천시스템 개발자에게 의미가 크다.

WHAT'S DIFFERENT

기존의 제로샷 프롬프팅이나 단순 합성 데이터 생성 방식 대비, 정보이론적 선택 전략(Jensen-Shannon, Fisher information)을 적용해 데이터 효율성과 선택 품질을 높였다는 점이 다르다.
