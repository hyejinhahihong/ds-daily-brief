★01AWS Bedrock, Z.ai GLM 5.3 출시 — 753B MoE 코딩·에이전트 모델, CyberGym 84.5점 기록Introducing GLM 5.3 on Amazon Bedrock✍️ 블로그 · aws.amazon.comZ.ai(Zhipu AI)의 GLM 5.3이 Amazon Bedrock에 완전관리형 API로 출시됐다.

753B 파라미터 MoE 구조로 코딩과 장시간 에이전트 작업에 최적화됐으며, DeepSWE·Terminal Bench 3.0·FrontierSWE 등에서 경쟁력 있는 성능을 보인다고 Z.ai는 밝혔다. 내부 코딩 벤치마크에서는 GLM 5.2 대비 50% 개선을 보고했으며, 벤치마크 자체가 갱신돼 GLM 5와의 직접 비교는 제공되지 않는다. 또한 CyberGym 벤치마크 84.5점을 기록하며 방어적 보안 워크플로우에 적합한 새로운 사이버보안 역량을 보여준다. Bedrock에서는 OpenAI 호환 API, 교차 리전 추론, 프롬프트 캐싱, 서비스 티어 등을 인프라 관리 없이 이용할 수 있다.

WHY IT MATTERS

오픈웨이트 대형 모델을 직접 운영 인프라 없이 완전관리형으로 쓸 수 있게 되면서, 대규모 코드베이스 리팩터링이나 멀티스텝 에이전트 워크플로우 같은 고난도 작업의 진입장벽이 낮아진다. 특히 보안 테스트 에이전트(Strix) 연동 사례는 모델의 사이버보안 활용 가능성을 구체적으로 보여준다.

WHAT'S DIFFERENT

기존 GLM 5 대비 코딩 성능과 사이버보안 역량이 크게 향상됐고, Bedrock 통합 측면에서도 교차 리전 추론 프로필과 암묵적·명시적 프롬프트 캐싱, OpenAI 호환 API의 기능 동등성이 새롭게 강화됐다.

01GS-Codec: A Gaussian-Splatting Bottleneck for Neural Audio CodingGS-Codec: 양자화기 없이 1D 가우시안 스플래팅으로 음성 압축, EnCodec·DAC와 동급 성능📄 논문 · arxiv.org · NeurIPS 2026GS-Codec은 VQ-VAE 기반 벡터양자화 대신 1차원 가우시안 스플래팅을 병목으로 쓰는 신경 음성 코덱이다.

인코더 구간을 가우시안 프리미티브들의 가중합으로 피팅하고, 디코더는 이를 렌더링해 파형을 복원한다. 추론 시 반복 최적화 비용을 없애기 위해 프리미티브 파라미터를 한 번의 순전파로 예측하는 경량 GS Predictor Net을 추가로 학습시켰다. 학습 파이프라인 전체에 양자화기가 없으며, 스칼라 양자화는 학습 후 피팅된 파라미터에만 적용된다. 하나의 체크포인트로 프리미티브 개수와 파라미터 비트 깊이를 조절해 재학습 없이 비트레이트를 세밀하게 제어할 수 있다.

WHY IT MATTERS

이산 코드북 단계 없이 연속적인 비트레이트 제어가 가능해지면, 음성 언어모델이나 실시간 통신에서 품질-용량 트레이드오프를 운영 중에 유연하게 조정할 수 있다는 점이 실질적 이점이다.

WHAT'S DIFFERENT

잔차 벡터양자화(RVQ), 유한 스칼라 양자화 등 기존 VQ-VAE 계열 코덱이 학습된 코드북이나 고정 격자로 잠재공간을 분할하는 것과 달리, GS-Codec은 학습 과정 전체에서 양자화기를 쓰지 않고 파라메트릭 신호 분해 자체를 병목으로 사용한다.

03PaLoRA: Paced Low-Rank Adaptation for Continual LearningPaLoRA, LoRA 연속학습에 '속도 조절 법칙' 도입 — 50태스크 ImageNet-A/R에서 정확도 4%p 개선📄 논문 · arxiv.org · NeurIPS 2026LoRA 기반 연속학습 기법들은 치명적 망각을 막기 위해 학습률을 작게 고정하는 경험적 방식을 써왔지만, 과거 지식의 유효 랭크가 커질수록 이 고정된 제약으로는 누적 망각을 막지 못한다는 점을 보인다.

저자들은 널스페이스 투영 같은 방향 제약 아래서도 유한 정밀도 업데이트가 여러 방향으로 과거 지식 서브스페이스에 누출됨을 밝히고, 이 누출을 상쇄하려면 그래디언트 크기 제약이 과거 업데이트의 유효 랭크 $R$에 따라 적응적으로 커져야 함을 이론적으로 도출했다($s^*=\sqrt{R/c}$ 페이싱 법칙). 이를 바탕으로 과거 지식을 적응형 SVD 절단으로 압축하고, 그래디언트를 이전 태스크의 널스페이스에 투영하며, 랭크 인식 적응 페이싱을 적용하는 PaLoRA를 제안한다. 실험에서 기존 방법들 대비 꾸준한 성능 향상을 보였으며, 특히 긴 태스크 시퀀스에서 강점을 보여 50개 태스크로 구성된 어려운 ImageNet-A, ImageNet-R 벤치마크에서 정확도 4%p 향상을 달성했다.

WHY IT MATTERS

연속학습의 고질적 문제인 안정성-가소성 트레이드오프를 경험적 하이퍼파라미터가 아닌 유효 랭크 기반 이론적 법칙으로 정식화했다는 점에서, 태스크 수가 많아지는 장기 연속학습 시나리오의 설계 원칙을 제시한다.

WHAT'S DIFFERENT

학습률을 고정된 휴리스틱으로 작게 유지하던 기존 LoRA 기반 연속학습 방법들과 달리, 과거 지식의 유효 랭크에 비례해 그래디언트 크기 제약을 적응적으로 조절하는 페이싱 법칙을 도입했다.

01Integrated Imputation-Classification for Supervised Learning with Missing Data결측치 있는 지도분류, 대치와 분류를 하나로 합친 IICN이 기존 파이프라인 능가📄 논문 · arxiv.org · NeurIPS 2026이 논문은 결측 특징값이 있는 지도분류 문제를 다룬다.

기존 방법들은 결측치 대치와 분류를 분리해 처리해, 그럴듯하지만 예측에는 쓸모없는 대치값을 만드는 경우가 많다는 문제의식에서 출발한다. 저자들은 대치기(imputer)와 (n+1)-클래스 판별기를 적대적으로 함께 학습시키는 IICN(Integrated Imputation and Classification Network)을 제안하며, 판별기는 n개의 실제 클래스와 추가된 '대치됨' 클래스를 구분하도록 학습된다. 전역 최적점에서 대치기와 판별기가 결측 좌표에 대한 주변화(marginalization)를 수행해 베이즈 최적 분류기를 산출함을 증명했다. FashionMNIST, CIFAR-10, 그리고 자연 발생 결측이 있는 표 데이터셋 실험에서 IICN은 기존 대치-후-분류 파이프라인과 최근 생성 모델 기반 베이스라인을 능가했다.

WHY IT MATTERS

실제 데이터에서 결측치는 피할 수 없는 문제이며, 대치와 분류를 분리하는 관행이 예측 성능 손실로 이어질 수 있다는 점을 이론적으로 짚어낸다. 단일 목적함수로 이론적 최적성(베이즈 최적)을 보장하면서 실증 성능도 확보했다는 점에서 결측치 처리 실무에 실질적 지침을 줄 수 있다.

WHAT'S DIFFERENT

기존의 대치 후 분류(impute-then-classify) 파이프라인 및 최근 생성 모델 기반 베이스라인과 달리, IICN은 대치와 분류를 하나의 지도분류 목적함수로 적대적 공동 학습시켜 분리로 인한 정보 손실을 피한다.

02TMAML: Temporal Model-Agnostic Meta-Learning for Cold-Start Time Series ForecastingTMAML, 콜드스타트 시계열 예측에 MAML 적용 — TFT 결합해 ERM 대비 우수하거나 동등한 성능 확인📄 논문 · arxiv.org · NeurIPS 2026콜드스타트 예측은 과거 데이터가 거의 없는 시계열을 예측하는 과제로, 적은 데이터로 빠르게 학습하고 관련 시계열 정보를 활용해 일반화하는 능력이 필요하다.

이 연구는 콜드스타트 예측을 few-window 학습 문제로 재정의하고, 소수 샷 신경망 적응을 위해 개발된 MAML을 시계열 예측에 맞게 변형한 Temporal Model-Agnostic Meta-Learning(TMAML)을 제안한다. TMAML은 시간적으로 일관된 support-query 윈도우로 메타태스크를 구성하고, 메타훈련·메타테스트 절차를 적용해 콜드스타트에 특화된 예측 모델을 만든다. Temporal Fusion Transformer(TFT)에 TMAML을 적용해 세 가지 콜드스타트 시나리오에서 평가한 결과, 표준 ERM 학습 TFT 대비 꾸준히 우수하거나 동등했고, 세 시나리오 중 두 곳에서 naive 대비 더 잘 보정된 예측을 보였으나 확률적 예측 정확도에서는 naive를 일관되게 능가하지는 못했다.

WHY IT MATTERS

실무에서 신규 제품·매장처럼 이력 데이터가 부족한 시계열 예측은 흔한 문제이며, 전역 예측 모델이 이런 상황에 최적화되어 있지 않다는 점을 메타러닝 기법으로 보완하려는 시도라 실용적 의미가 크다.

WHAT'S DIFFERENT

표준 ERM 방식으로 학습된 TFT 대비 콜드스타트 적응에 특화된 메타훈련 절차를 도입한 점이 다르지만, 확률적 예측 정확도에서는 naive 기법 대비 일관된 우위를 보이지 못했다.

01Local Fisher Information Enables Sparse Causal DiscoveryFiCS 알고리즘, 국소 Fisher 정보로 고차원 희소 인과 발견 — n이 p보다 작을 때 최대 성능📄 논문 · arxiv.org이 논문은 가법 잡음 모델에서 변수 순서 결정과 부모 노드 선택에 동일한 국소 Fisher 점수를 사용하는 source-first 알고리즘 FiCS를 제안한다.

조건부 집합이 모든 부모를 포함하고 자손을 포함하지 않을 때, 노드의 국소 Fisher 정보가 잡음의 Fisher 정보와 정확히 일치함을 증명하여 이를 부모 집합 식별에 활용한다. 최대 조건부 집합 크기 q가 최대 진입차수 d 이상이면 FiCS는 최대 q+1개 변수의 주변분포만으로 참 DAG를 복원하며, 조건부 집합 크기를 d에 가깝게 줄일수록 순서 마진이 감소하지 않고 오히려 커질 수 있음을 보였다. 정규화 커널 Stein 추정량에 대해서는 q{1+log(p/q)}+log p=o(n) 조건 하 고차원 DAG 일관성을 증명했다. 실험에서는 n이 p에 비해 작을 때 가장 큰 성능 향상을 보였고 세 가지 실제 데이터 벤치마크에서 경쟁력 있는 참조 그래프 복원 성능을 확인했다.

WHY IT MATTERS

고차원 밀도 추정 없이 그래프 구조를 활용하는 방식이어서, 변수 수가 표본 수보다 많은 실제 환경(유전체, 센서 데이터 등)에서 인과 발견의 실용성을 높일 수 있다.

WHAT'S DIFFERENT

조건부 분산 기반 순서 결정이나 leaf-first Fisher 순서 방식과 달리, 순서 결정과 부모 선택을 하나의 국소 Fisher 점수로 통합하고 조건부 집합 크기를 작게 유지할수록 순서 마진이 커진다는 점을 이론적으로 보인 것이 차별점이다.

02Matched Triple-Differences: A Framework for Covariate Adjustment삼중차분(DDD)의 3WFE 회귀는 공변량 매칭 추정과 다른 결론 — 매칭 기반 새 프레임워크 제안📄 논문 · arxiv.org삼중차분(DDD) 분석에서 공변량 추세나 수준을 3원 고정효과(3WFE) 회귀에 포함시키는 통상적 방법은 조건부 평행추세 가정을 전제로 한다.

연구진은 두 3WFE 설정 모두 일반적으로 처치군 평균처치효과(ATT)를 일관되게 추정하지 못함을 보인다. 이는 OLS 추정량이 ATT와 같아지기 위한 충분조건인 공변량 균형 조건을 충족하지 못하기 때문이며, 각 추정량이 ATT와 같아지려면 추가 가정이 필요함을 규명했다. 이를 해결하기 위해 최근접이웃 매칭, 커널 매칭 등을 포괄하는 매칭 기반 삼중차분 프레임워크를 제안하고, 일관된 매칭 추정량과 그 점근정규성, 매칭 단계에서 발생하는 변동성을 반영한 분산 추정량을 제시했다. 실증 분석에서 제안된 매칭 삼중차분 추정량은 3WFE 회귀와 다른 추정치 및 결론을 도출함을 보였다.

WHY IT MATTERS

DDD는 정책·인과추론 연구에서 널리 쓰이는 식별 전략인데, 흔히 쓰는 3WFE 공변량 보정 방식이 이론적으로 ATT를 보장하지 못한다는 점은 기존 실증 연구의 신뢰성에 의문을 제기한다.

WHAT'S DIFFERENT

기존에 널리 쓰이던 3WFE 회귀 기반 공변량 조정 대비, 매칭 절차의 변동성까지 반영한 일관된 매칭 추정량과 분산 추정법을 제시한 점이 다르다.

01PhaseGate: Phase-Aware CPU Retrieval Scheduling for On-Device LLMs on Unified MemoryPhaseGate, 온디바이스 LLM CPU 검색 스케줄링 — p95 지연 1.25배 내 유지하며 처리량 2.0배 달성📄 논문 · arxiv.org · NeurIPS 2026유니파이드 메모리 기반 온디바이스 어시스턴트는 GPU LLM 추론과 CPU 검색을 동시에 수행하는데, 검색 워커 4개가 동시 실행되면 M4 시스템에서 디코드 p95 지연이 60~61% 증가하는 반면 prefill 지연은 5.7~6.9%만 증가함을 확인했다.

이에 LLM의 현재 단계(prefill/decode)를 CPU 검색 허용 신호로 활용하는 PHASEGATE를 제안하며, prefill과 decode에 각각 별도의 동시성 한도(기본 M4 구성에서 4와 1)를 보정해 적용한다. 백로그가 쌓인 큐 환경에서 PHASEGATE는 테스트된 최선의 고정 정책 대비 집계 검색 처리량 2.0배를 달성하면서도, 7개의 홀드아웃 실행 모두에서 두 가지 p95 LLM 지연 지표를 검색 미실행 기준 대비 1.25배 이내로 유지했다. 반면 LLM 단계를 보지 않고 동일한 두 한도를 보정된 스케줄로만 적용하는 TimeGate는 비슷한 검색 처리량을 보이지만 모든 실행에서 출력 토큰 지연 한도를 위반했다. M2와 M2 Pro Mac mini에서도 정책 순서가 재현되었고, 출력 길이가 길어져 decode 비중이 커질수록 이점이 줄어드는 경향을 보였다.

WHY IT MATTERS

온디바이스 LLM 어시스턴트가 로컬 검색(RAG)을 함께 수행할 때 CPU 자원 경합으로 사용자 체감 지연이 급격히 악화될 수 있는데, 이를 제어하는 실용적 스케줄링 신호를 제시한다는 점에서 온디바이스 추론 품질 관리에 바로 적용 가능한 시사점을 준다.

WHAT'S DIFFERENT

LLM의 prefill/decode 단계를 관찰하지 않고 시간 기반 고정 스케줄만 사용하는 TimeGate 대비, PHASEGATE는 단계를 인지한 적응형 허용 제어로 지연 한도 위반 없이 동일 수준의 처리량을 달성한다는 점이 핵심 차별점이다.

02QuantWM: Temporally Consistent 2-Bit KV Cache Quantization for Video World ModelsQuantWM, 비디오 월드모델용 2비트 KV 캐시 양자화 — 시간적 플리커링 없이 최대 6.20배 압축📄 논문 · arxiv.org비디오 월드모델은 장기적 시간 일관성을 위해 생성 중 KV 캐시를 저장하는데, 캐시가 커질수록 메모리 병목이 심해져 저비트 양자화가 요구된다.

LingBot-World-v2, HY-World 1.5, Matrix-Game-2 등 5개 벤치마크에서 기존 방법 대비 화질과 시간 일관성을 개선하며 최대 6.20배 KV 캐시 압축을 달성했다.

WHY IT MATTERS

긴 영상을 생성하는 월드모델은 KV 캐시 메모리가 실배포의 핵심 병목인데, 단순 양자화가 시간적 깜빡임 같은 치명적 결함을 낳는다는 점을 짚어 효율화와 품질 간 트레이드오프를 재조명한다.

WHAT'S DIFFERENT

VBench 기준으로는 거의 손실 없는 기존 2비트 KV 양자화 기법들과 달리, QuantWM은 Key 양자화가 어텐션 로짓과 토큰 선택을 왜곡한다는 원인을 규명하고 이를 직접 보정하는 QSAC·PSAC를 도입했다.
