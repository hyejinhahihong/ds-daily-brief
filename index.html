01Apple, Normalizing Trajectory Models(NTM) 공개 — 소수 스텝에서도 정확한 우도 학습 유지Normalizing Trajectory Models✍️ 블로그 · machinelearning.apple.com기존 디퓨전 모델은 샘플링을 다수의 작은 가우시안 디노이징 스텝으로 쪼개는데, 생성 과정을 몇 개의 거친 전환 스텝으로 압축하면 이 가정이 깨진다.

기존 few-step 방법들은 distillation, consistency training, 적대적 목적함수 등으로 이를 해결하지만 그 과정에서 우도 기반 프레임워크를 희생한다. 이 논문은 각 역방향 스텝을 표현력 있는 조건부 normalizing flow로 모델링해 정확한 우도 학습을 유지하는 Normalizing Trajectory Models(NTM)를 제안한다. 구조적으로는 각 스텝 내 얕은 invertible 블록과 깊은 병렬 구조를 결합한다.

WHY IT MATTERS

소수 스텝 생성과 정확한 우도 학습을 동시에 달성하면 빠른 샘플링과 모델 평가·비교 가능성을 모두 챙길 수 있어 생성 모델 연구에서 중요한 트레이드오프를 해소할 잠재력이 있다.

WHAT'S DIFFERENT

distillation, consistency training, 적대적 학습 기반 기존 few-step 방법들이 우도 프레임워크를 포기하는 것과 달리, NTM은 conditional normalizing flow 구조로 정확한 우도 학습을 유지한다.

02Continuous Memory MachinesSakana AI, CMM 공개 — 단기·장기 메모리 분리한 순환 신경망으로 기존 메모리 증강 네트워크보다 강한 일반화 달성📄 논문 · arxiv.org · NeurIPS 2026이 논문은 단일 벡터 상태에 단기·장기 정보를 모두 압축해야 했던 기존 RNN의 한계를 지적하며, Continuous Thought Machine(CTM)을 발전시킨 Continuous Memory Machine(CMM)을 제안한다.

CMM은 행렬 형태의 단기 메모리와 장기 메모리를 별도로 두어 각각 최근 신경 활동 추적과 정보의 장기 보존이라는 다른 역할을 수행하게 한다. Transformer가 두 메모리 저장소를 공동으로 갱신하며, 각 저장소가 스스로의 내용을 재구성하고 서로 읽고 쓰는 양방향 읽기-쓰기 메커니즘을 제공한다. 알고리즘, 인-컨텍스트 학습, 순환 추론 과제 전반에서 CMM은 다양한 베이스라인을 능가했고, 기존 메모리 증강 네트워크보다 더 강한 일반화를 보이면서 CTM의 해석 가능한 주의 패턴도 유지했다.

WHY IT MATTERS

단기 연산과 장기 기억을 하나의 표현에 뭉뚱그리던 구조적 병목을 메모리 역할 분리로 해결한 접근은, 장기 문맥 추론과 지속적 학습이 필요한 에이전트형 모델 설계에 참고할 만한 아키텍처 아이디어를 제공한다.

WHAT'S DIFFERENT

단일 벡터 순환 상태에 의존하던 기존 RNN 및 CTM 대비, 단기·장기 메모리를 행렬 형태로 분리하고 Transformer 기반 양방향 읽기-쓰기로 두 저장소를 상호작용시킨다는 점이 다르다.

03ORCA: Hunting Compositional Failures in Text-to-Image DiffusionORCA, 텍스트-이미지 디퓨전의 구성적 바인딩 오류 해결 — DiT-L/2서 FID 16.65·GenEval 0.291, 절반 학습비용으로 400K 베이스라인 능가📄 논문 · arxiv.org · NeurIPS 2026텍스트-투-이미지 디퓨전 모델은 속성이 엉뚱한 객체에 붙거나 공간 관계가 뒤바뀌는 등 구성적 프롬프트에서 예측 가능한 실패를 보인다.

저자들은 이 문제가 정보 부족이 아니라 언어모델링 공간과 시각 공간 간의 정렬 불일치 때문이며, 디노이징 목적함수가 둘의 정렬을 직접 보상하지 않는다고 주장한다. ORCA(Orthogonal Residual Compositional Alignment)는 디퓨전 트랜스포머의 잠재변수를 고정된 시각 인코더에서 유도한 저랭크 타깃과 정렬시키는 보조 손실을 추가하며, T5와 CLIP 임베딩 간 학습된 잔차로 매개변수화된 직교 기저 예측기를 사용해 프롬프트에 의존적인 시각 서브공간을 선택한다. 특정 랭크에서 복원 가능한 교차모달 정보량은 시각 인코더 공분산의 상위 성분 스펙트럼 질량으로 상한이 증명된다. DiT-B/2, DiT-L/2, U-ViT-L 세 백본에서 vanilla 및 REPA 베이스라인 대비 FID와 GenEval을 개선했으며, DiT-L/2는 200K 스텝 만에 FID 16.65, GenEval 0.291로 400K 스텝 최강 베이스라인을 절반 비용으로 능가했다.

WHY IT MATTERS

속성 바인딩, 공간 관계, 다중 객체 처리는 생성 모델의 고질적 약점으로, 이를 추론 비용 증가 없이 학습 단계의 보조 손실만으로 해결했다는 점이 실용적이다.

WHAT'S DIFFERENT

기존 CLIP-T5 결합 아키텍처나 REPA 방식이 정보 부족 관점에서 접근한 것과 달리, ORCA는 정보는 이미 존재하되 표현 공간이 정렬되지 않은 것이 문제라고 보고 저랭크 시각 서브공간 정렬을 명시적 학습 신호로 제공한다.

01FlowCF: Sparse Counterfactual Explanations for Mixed-Type Tabular Data using Flow MatchingFlowCF, 혼합형 표 데이터 반사실 설명을 flow matching으로 — 수치 특성 변경 29%, 이동거리 70% 감소📄 논문 · arxiv.org · NeurIPS 2026FlowCF는 모델 결정을 설명하는 반사실(counterfactual) 설명 생성을 사실 클래스에서 목표 클래스로의 희소한 전송(transport) 문제로 재구성한 모델-애그노스틱 생성 방법이다.

이 전송 문제를 flow matching으로 풀며, 범주형과 수치형이 섞인 혼합 특성 유형을 다루기 위해 새로운 mixed flow operator를 제안한다. 또한 게이팅 네트워크를 이용해 전송이 변경하는 특성 수를 최소화함으로써 희소성을 최적화한다. 6개 벤치마크 데이터셋 실험에서 FlowCF는 최고의 수치 희소성과 근접성을 보였으며, 기존 최선 베이스라인이 수치 특성의 89%를 변경하는 데 비해 29%만 변경하면서 이동 거리도 70% 더 작았다.

WHY IT MATTERS

반사실 설명은 실무에서 모델 결정을 바꾸기 위해 어떤 입력을 얼마나 바꿔야 하는지 알려주는 핵심 XAI 도구인데, 특성을 적게 바꾸면서도 변화량을 최소화하는 것이 실용성의 관건이다. 혼합형 표 데이터에 특화된 희소성 개선은 금융·의료 등 실제 의사결정 설명 시스템에 바로 적용 가능하다는 점에서 의미가 크다.

WHAT'S DIFFERENT

기존 모델-애그노스틱·분할상환(amortised) 방법과 모델에 완전 접근하는 그래디언트 기반 방법 모두 수치 특성의 희소성·근접성에서 한계가 있었는데, FlowCF는 flow matching 기반 전송과 게이팅 네트워크로 이를 개선했다.
