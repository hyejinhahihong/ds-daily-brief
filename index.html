★02AWS AgentCore Gateway, MCP 2026-07-28 스펙 지원 — 세션 제거로 완전 무상태 프로토콜 전환How AgentCore Gateway supports the MCP 2026-07-28 spec✍️ 블로그 · aws.amazon.comMCP 2026-07-28 스펙은 프로토콜 출시 이후 가장 큰 변화로, initialize 핸드셰이크와 Mcp-Session-Id 세션을 제거해 완전한 무상태(stateless) 프로토콜로 전환된다.

이제 프로토콜 버전, 클라이언트 정보, 기능이 각 요청의 _meta 파라미터에 포함되어 단일 도구 호출이 자체 완결적으로 처리되고 어떤 서버 인스턴스로도 라우팅될 수 있다. 이와 함께 거버넌스 확장 시스템, OAuth 2.0/OpenID Connect 기반 인가 강화, 향후 호환성 붕괴를 막는 기능 수명주기 정책이 도입됐다. Amazon Bedrock AgentCore의 AgentCore Gateway는 UpdateGateway 호출로 지원 버전 목록을 설정해 오늘부터 새 프로토콜을 opt-in 방식으로 사용할 수 있으며, 기존 클라이언트는 영향 없이 그대로 동작한다.

WHY IT MATTERS

세션 기반 아키텍처는 로드밸런서 sticky session이나 공유 세션 스토어가 필요해 엔터프라이즈 규모 확장에 걸림돌이었는데, 무상태화로 원격 MCP 서버가 표준 HTTPS 엔드포인트처럼 수평 확장이 가능해진다. 에이전트/도구 개발자는 프로토콜 버전 관리와 하위 호환성 전략을 미리 이해해야 마이그레이션 리스크를 줄일 수 있다.

WHAT'S DIFFERENT

기존 MCP 프로토콜은 initialize/initialized 핸드셰이크와 Mcp-Session-Id로 클라이언트를 특정 서버에 고정시켰던 반면, 2026-07-28 스펙은 이를 제거하고 매 요청에 버전·기능 정보를 담아 세션 없이 어떤 서버로도 라우팅 가능하게 바뀐 것이 핵심 차이다.
