01NVIDIA, 30B MoE 경량 모델 'Nemotron 3.5 Lightning' 공개 — 3B 활성 파라미터로 에이전트 실행 단계 전담NVIDIA Nemotron 3.5 Lightning Delivers Fast, Accurate Specialized Task Execution for Long-Running Agents✍️ 블로그 · developer.nvidia.comNVIDIA가 장시간 실행되는 AI 에이전트의 도구 호출, 결과 검증, 서브에이전트 위임 같은 반복적 실행 작업을 위한 모델 Nemotron 3.5 Lightning을 공개했다.

이 모델은 30B 규모 MoE(Mixture-of-Experts) 구조에 3B 활성 파라미터만 사용해 매 실행 단계마다 프론티어 추론 모델을 호출할 때 발생하는 비용과 지연을 줄이도록 설계됐다. 상시 동작하는 에이전트 하네스에서 고빈도 실행 계층을 전담하는 용도로 만들어졌다.

WHY IT MATTERS

에이전트 워크플로에서 모든 단계에 대형 추론 모델을 쓰는 대신 경량 모델을 실행 전담으로 분리하면 운영 비용과 응답 지연을 크게 줄일 수 있어 실서비스 에이전트 아키텍처 설계에 참고할 만하다.

WHAT'S DIFFERENT

매 실행 단계마다 프론티어 추론 모델을 사용하는 기존 방식과 달리, 실행 전담 경량 MoE 모델을 별도로 두어 추론과 실행을 역할 분리한 것이 특징이다.

02Activation Probes Surface Code-Security Signals that the Model's Output Misses코드 보안 취약점 탐지, 리뷰어 모델의 프롬프트 답변 대신 활성화 프로브가 61~67%로 우월📄 논문 · arxiv.org · ICML 2026AI 코딩 에이전트가 작성한 코드를 검증하기 위해, 오픈 웨이트 리뷰어 모델의 내부 활성화(activation)를 읽어 보안 신호를 추출할 수 있는지 검토했다.

취약-수정 함수 쌍 데이터로 선형 프로브를 하나씩 학습시킨 뒤, 학습에 없던 실제 공개 취약점 유형에 대해 5개의 오픈 웨이트 리뷰어 모델로 재학습 없이 테스트했다. 단일 함수 수정으로 고쳐진 취약점의 경우, 모든 모델에서 프로브가 취약한 함수에 수정된 함수보다 높은 점수를 매긴 비율이 61~67%로 우연 수준(50%)을 넘어섰다. 또한 이 프로브는 같은 모델의 프롬프트 기반 YES/NO 응답의 로짓 승률보다도 모든 프롬프트에서 더 우수했다. 체인 오브 소트를 포함해 서면 판정을 요청해도 취약 함수와 수정 함수에 대해 대부분 같은 답을 내놓아 구분하지 못했다.

WHY IT MATTERS

인간의 보안 리뷰가 코드 생성 속도를 따라가지 못하는 상황에서, 폐쇄형 코딩 에이전트의 출력을 검증할 오픈 웨이트 리뷰어의 활성화를 활용하면 프롬프트만으로는 놓치는 보안 신호를 회수할 수 있음을 보여준다.

WHAT'S DIFFERENT

동일한 리뷰어 모델에 직접 YES/NO로 묻거나 체인 오브 소트로 서면 판정을 받는 프롬프트 기반 평가 대비, 모델 내부 활성화에 대한 선형 프로브가 취약/수정 함수를 더 잘 구분한다는 점이 핵심 차이다.

★01Efficient Test-Time Scaling for LLM-based Time Series ForecastingKDD 2026, SCALER 공개 — 경량 Transformer 형태 예측으로 LLM 시계열 테스트타임 스케일링 비용 절감📄 논문 · arxiv.org · KDD 2026SCALER는 장기 시계열 예측에서 트렌드·계절성 같은 전역 구조를 보존하기 위한 coarse-to-fine 프레임워크다.

먼저 경량 Transformer가 미래 동역학의 대략적인 형태(coarse representation)를 예측하고, 이를 LLM이 반복적인 coarse-to-fine 잔차 토큰 정제를 수행하는 데 필요한 압축된 가이드로 사용한다. 이 방식은 각 단계에서 처리하는 토큰 수를 크게 줄이며, 명시적 형태 예측으로 정제 과정을 안내함으로써 긴 설명 프롬프트에 대한 의존도를 낮춘다. 고정된 정제 단계를 사용해 비용이 큰 리워드 모델 기반 선택도 피한다. 실험 결과 SCALER는 장기·단기·zero-shot 예측 모두에서 강력한 베이스라인을 앞서면서 LLM 기반 스케일링의 추론 비용을 크게 줄였다.

WHY IT MATTERS

LLM 기반 시계열 예측은 테스트타임 스케일링으로 정확도를 높이지만 계산 비용이 크고 예측 구간이 길어질수록 전역 형태 불일치 문제가 심해지는데, SCALER는 이 두 문제를 동시에 해결하는 실용적 접근을 제시한다.

WHAT'S DIFFERENT

기존 반복적 정제나 리워드 모델 기반 선택을 사용하는 LLM 테스트타임 스케일링 방법 대비, 경량 Transformer의 형태 예측을 가이드로 활용해 긴 프롬프트와 리워드 모델 선택 비용 없이 고정 단계로 정제를 수행한다.

클라우드 플랫폼을 통한 배포로 기업이 별도 인프라 구축 없이 AI 기반 보안 기능을 도입할 수 있게 되어 엔터프라이즈 보안 시장에서 AI 활용 확산을 촉진할 수 있다.
