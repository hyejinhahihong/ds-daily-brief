★01Georgia State TReNDS, Amazon Bedrock와 Strands Agents로 근본원인분석 자동화 — 조사시간 15~30분→실시간How TReNDS automates root-cause analysis with Amazon Bedrock✍️ 블로그 · aws.amazon.comTReNDS 센터는 Amazon EKS에서 실행되는 애플리케이션의 CloudWatch 로그를 대상으로, 에러 패턴을 감지하면 Lambda가 Strands Agents SDK 기반 에이전트를 실행해 Amazon Bedrock 파운데이션 모델로 근본원인을 분석하는 아키텍처를 구축했다.

CloudWatch 구독 필터가 ERROR, Exception, FATAL, CRITICAL 등의 패턴을 감지하면 Lambda를 트리거하고, 에이전트가 로그 컨텍스트와 GitHub 소스코드를 함께 조회해 구조화된 분석 결과를 만든 뒤 SNS를 통해 팀에 전달한다. 기존에는 엔지니어가 CloudWatch Logs를 열어 스택 트레이스를 읽고 관련 소스 파일을 찾아 실행 경로를 추적하는 데 단순 오류도 15~30분이 걸렸다. 모델이 어떤 도구를 언제 호출할지 직접 결정하기 때문에 조사 경로를 미리 하드코딩하지 않아도 된다. 헬스케어 연구 데이터를 다루는 특성상 Bedrock이 자체 AWS 계정 내에서 요청을 처리해 데이터가 외부로 나가지 않는 점도 HIPAA 관련 컴플라이언스 측면에서 중요했다.

WHY IT MATTERS

장애 발생 시 알림만으로는 원인 파악이 안 되는 문제를 에이전트가 로그와 코드를 스스로 탐색해 해결하는 실제 프로덕션 사례로, 에이전틱 워크플로우가 인시던트 대응 시간을 실질적으로 줄일 수 있음을 보여준다.

WHAT'S DIFFERENT

기존 모니터링·알림 체계가 오류 발생 사실만 알려주던 것과 달리, 모델이 직접 도구 사용 경로를 결정해 로그 컨텍스트와 소스코드를 탐색하며 분석하는 자율적 조사 방식을 도입했다는 점이 다르다.

01Apple, Categorical Flow Maps 대규모 언어모델로 확장 — 연속 생성으로 빠른 샘플링 구현Scaling Categorical Flow Maps✍️ 블로그 · machinelearning.apple.com이 블로그는 연속 확산·플로우 매칭 모델을 언어 모델링에 적용하는 방법을 다룬다.

최근 연구들은 가우시안 분포와 원-핫 인코딩된 데이터 분포 사이의 단순한 플로우 매칭 과정을 통해 이산 데이터를 연속적으로 생성할 수 있음을 보였다. 이를 기반으로 한 Categorical Flow Maps(CFMs)는 가속화된 샘플링을 가능하게 하면서도 경쟁력 있는 샘플 품질을 달성했다. 이 글은 이러한 CFM 접근법을 더 큰 규모로 확장하는 방법을 탐구한다.

WHY IT MATTERS

자기회귀 방식이 지배적인 언어 모델링 분야에서 연속 생성 모델이 가속 샘플링과 틸팅 같은 이점을 제공할 수 있다면, 향후 LM 아키텍처의 대안적 패러다임으로 자리잡을 가능성이 있다.

WHAT'S DIFFERENT

기존 자기회귀 언어 모델과 달리, 가우시안 분포에서 원-핫 인코딩된 데이터로 향하는 플로우 매칭 과정을 통해 이산 텍스트 데이터를 연속적으로 생성한다.

02DyPES-VLA: Learning Shared Dynamics Priors and Embodiment-Specific Control for Cross-Embodiment ManipulationDyPES-VLA, 이종 로봇 조작 통합 정책 제안 — LIBERO 98.0%·RoboTwin2.0 89.02% 달성📄 논문 · arxiv.orgDyPES-VLA는 서로 다른 로봇 임베디먼트를 위한 범용 조작 정책을 학습하는 Vision-Language-Action 모델이다.

WHY IT MATTERS

이종 로봇 하드웨어 간 정책 전이는 로봇 학습의 핵심 병목인데, 수작업 액션 정렬 없이 범용 정책을 학습할 수 있다면 데이터 활용 범위와 배포 확장성이 크게 개선된다.

WHAT'S DIFFERENT

기존 방법들은 이종 로봇 데이터 간 공유 동역학 정보를 충분히 활용하지 못하고 임베디먼트별 액션을 공통 포맷으로 수작업 변환해야 했던 반면, DyPES-VLA는 미래 예측 기반 공유 동역학 학습과 임베디먼트별 MoE 액션 헤드로 이 두 한계를 동시에 해결한다.

03MASS: Multiplayer World Models with Authoritative Shared StateMAS, 월드 모델과 렌더링 분리해 멀티플레이어 시뮬레이션 강화 — 1,024명 동시 플레이어 1만 스텝 검증📄 논문 · arxiv.org기존 비디오 월드 모델은 월드 상태와 시점별 시각 잠재변수를 뒤섞어 표현하기 때문에 멀티플레이어 환경에서 연산 낭비, 시점 간 불일치, 확장성 저하 문제를 겪는다.

MAS는 멀티플레이어 게임 아키텍처에서 착안해 월드 동역학과 뷰 렌더링을 분리한다. 학습된 Logic Engine이 수작업 전이 함수 없이 공동 행동으로부터 전역적이고 권위 있는 타입 상태를 갱신하며 유일한 순환 메모리이자 동기화 기준 역할을 하고, 이 공유 상태로부터 Rendering Engine이 요청된 카메라별로 독립적이면서 일관된 뷰를 생성한다. 매칭된 멀티플레이어 Snake 벤치마크에서 MAS는 최신 멀티뷰 베이스라인 대비 더 높은 상태 정확도와 낮은 시점 간 불일치를 달성했다. 또한 1,024명 동시 플레이어를 대상으로 10,000 순환 스텝까지 예측 월드를 진행시켰다.

WHY IT MATTERS

멀티플레이어·다중 에이전트 시뮬레이션은 게임, 로보틱스, 사회적 AI 등에서 확장성이 핵심 병목인데, 명시적 상태-렌더링 분리가 이를 실용적으로 해결할 기반이 될 수 있음을 보여준다.

WHAT'S DIFFERENT

WHY IT MATTERS

WHAT'S DIFFERENT
