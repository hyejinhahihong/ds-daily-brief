★01AWS, SageMaker AI MTRL로 검색 에이전트 미세조정 — 소형 모델로 프론티어급 신뢰성 확보Fine-tune a search agent with multi-turn RL on Amazon SageMaker AI✍️ 블로그 · aws.amazon.com이 글은 Amazon SageMaker AI의 멀티턴 강화학습(MTRL) 기능으로 검색 에이전트를 미세조정한 사례를 다룬다.

검색 에이전트는 여러 차례 상호작용을 거치며 검색어와 검색 전략, 중단 시점을 스스로 결정해야 하는데, 지도 미세조정(SFT)은 전문가의 시연 데이터가 필요하고 단일턴 RL(RLVR)은 턴 간 상관관계를 놓친다는 한계가 있다. MTRL은 전체 멀티턴 궤적 단위로 에이전트를 최적화하며 최종 결과에 대한 보상만 있으면 학습이 가능하다. SageMaker AI MTRL은 모듈형 에이전트-환경 인터페이스, 서버리스 실행, 비동기 롤아웃, PPO·CISPO·GRPO 등 알고리즘 라이브러리, 재개 가능한 학습, MLflow 기반 궤적 관찰, 평가 작업 기능을 제공한다.

WHY IT MATTERS

소형 모델에 환경별 도구 사용법을 직접 학습시켜 프론티어 모델 수준의 신뢰성을 더 낮은 지연과 비용으로 얻을 수 있다는 점에서, 비용과 성능 사이에서 고민하는 실무자에게 실질적 대안이 된다.

WHAT'S DIFFERENT

기존 지도 미세조정(SFT)이 수집 비용이 큰 전문가 시연 궤적에 의존하고, 단일턴 RL(RLVR)이 턴 간 의존성을 무시한 채 한 응답씩 평가하는 것과 달리, MTRL은 전체 멀티턴 상호작용 시퀀스를 하나의 단위로 최적화한다.

01DashVMC: Real-Time Discrete World Model Control in Geometry DashDashVMC: Geometry Dash 2시간 녹화만으로 학습한 월드모델, 가상 롤아웃만으로 PPO 정책 개선해 생존시간 늘려📄 논문 · arxiv.org · NeurIPS 2026DashVMC는 약 2시간 분량의 Geometry Dash 플레이 영상으로부터 행동 조건부 월드모델을 학습한다.

컨트롤러는 행동 복제(BC)로 초기화된 뒤, 실제 게임과의 추가 상호작용 없이 오직 고정된 학습 모델 내 롤아웃만으로 PPO를 통해 개선된다. 세 가지 컨트롤러 시드 모두에서 개선된 정책은 BC 초기 정책보다 공식 레벨 3종과 커뮤니티 제작 레벨에서 더 오래 생존했다. 배포 시에는 시각 생성을 생략한 베이스라인이 소비자용 GPU에서 60Hz 캡처-행동 루프를 유지한다. 롤아웃 진단 결과 장기 예측 정확도는 완벽하지 않지만 모델이 제어용으로 여전히 유용함을 보여준다.

WHY IT MATTERS

시뮬레이터가 아닌 실시간 라이브 게임 환경에서 캡처-예측-행동을 다음 프레임 전에 처리해야 한다는 제약은, 월드모델 기반 에이전트가 실제 저지연 응용으로 확장될 수 있는지를 가늠하는 시험대가 된다.

WHAT'S DIFFERENT

기존 월드모델 평가가 정책의 대기를 허용하는 시뮬레이터 중심이었던 것과 달리, 이 연구는 실시간 60Hz 제약 하에서 실제 게임과의 추가 상호작용 없이 고정 모델 롤아웃만으로 정책을 개선하는 설정을 검증한다.

02Loop-Free Inverse Reinforcement Learning via Sequential Value Recovery with Q-Score MatchingNeurIPS 2026, 루프 없는 역강화학습 LFIRL 제안 — 기존 대비 2-3배 빠르면서 보상 복원 성능 유지📄 논문 · arxiv.org · NeurIPS 2026기존 역강화학습(IRL)은 보상 학습과 정책 최적화를 번갈아 반복하는 이중 최적화 구조 때문에 계산 부담과 학습 불안정성이 컸다.

이 연구는 디퓨전 정책이 최적 소프트 Q함수의 행동-그래디언트 구조를 인코딩한다는 통찰을 바탕으로, 보상 학습을 일련의 가치 복원 문제로 바꿔 정책 최적화 루프 자체를 제거했다. 방법은 행동-그래디언트 매칭으로 소프트 Q함수와 소프트 가치함수를 복원하고, 상태 의존적 오프셋으로 보정한 뒤, 벨만 일관성을 적용해 보상을 추출하는 3단계로 구성된다. 이렇게 완성된 LFIRL(Loop-Free IRL)은 완전 오프라인이며 단순하고 순차적인 알고리즘이다. Maze, Franka Kitchen, Adroit Hand Pen, Push-T 벤치마크에서 가장 빠른 기존 방법 대비 2-3배 속도 향상을 보이면서도 보상 복원 품질은 최신 기법과 동등하거나 이를 능가했다.

WHY IT MATTERS

보상-정책 반복 루프를 제거하면서도 성능을 유지했다는 점은 IRL의 고질적인 학습 불안정성과 비용 문제를 근본적으로 다루는 접근으로, 오프라인 강화학습 및 모방학습 전반의 효율화에 영향을 줄 수 있다.

WHAT'S DIFFERENT

WHAT'S DIFFERENT

02Raw-Routed Mixture of Adapters: A Causal Intervention for Routing Collapse in Time Series Foundation Models시계열 파운데이션 모델의 '라우팅 붕괴' 원인 규명 — Raw-Routed MoA, 54/54 비교서 전승📄 논문 · arxiv.org · NeurIPS 2026시계열 파운데이션 모델(TSFM)에 믹스처 오브 익스퍼트(MoE) 헤드를 붙이면 인스턴스 정규화 구조 때문에 라우팅 엔트로피가 0으로 붕괴해 하나의 익스퍼트만 모든 입력을 처리하는 현상이 발생한다.

저자들은 이를 '정규화 유발 라우팅 붕괴'로 명명하고, 상호정보량 분해로 원인이 라우터 입력 자체(사전 정규화가 통계 정보를 제거)임을 규명했으며, 훈련 전 계산 가능한 신호비율이 데이터셋 취약성을 스피어만 상관 -0.88로 예측함을 보였다. 8가지 인과 통제 실험(비전 모달리티 복제 포함)으로 인스턴스 정규화를 원인으로 특정했다. 해법으로 제안된 Raw-Routed Mixture of Adapters(RR-MoA)는 정규화 이전의 원본 입력으로 라우팅하며, 백본을 완전히 고정한 상태에서 최강 고정 어댑터 대비 54/54 비교에서 전승하고 LoRA, TRACE, AdaMix, 풀 파인튜닝보다 유의하게 우수했다. 여섯 개 백본과 보간(imputation) 과제에서도 효과가 일반화되었고, 고정된 RR-MoA는 풀 파인튜닝을 12-79% 능가하는 '고정 역설(Frozen Paradox)'도 확인했다.

WHY IT MATTERS

MoE를 TSFM에 단순 적용하면 성능 향상은커녕 라우팅이 붕괴해 사실상 단일 전문가 모델로 퇴화하는 흔한 함정을 진단하고, 원인을 최적화가 아닌 입력 설계에서 찾았다는 점이 실무적으로 중요하다. 백본을 전혀 건드리지 않고도 풀 파인튜닝을 능가한다는 결과는 저비용 적응 전략의 근본적 재설계를 시사한다.

WHAT'S DIFFERENT

기존 LoRA, TRACE, AdaMix 등 파라미터 효율적 적응 기법 및 표준 MoE 복구 기법(라우터 최적화 개선) 대비, 문제의 근원을 라우터 최적화가 아닌 '정규화 이전 입력의 정보 손실'로 재정의하고 라우팅 입력 자체를 원본 데이터로 바꾸는 최소 개입(RR-MoA)을 제시한 점이 다르다.

기존 RAG(유사도 검색)는 구조적으로 '전체를 검사했다'는 완결성을 증명할 수 없고, text-to-SQL은 생성된 쿼리가 모집단을 몰래 축소시켜도 결과가 정확해 보이는 위험이 있는데, Adjudicated Query는 AI의 역할을 질의 번역과 결과 서술로 한정하고 판정 자체는 결정론적 규칙 엔진에 맡겨 이 두 문제를 해결한다.
