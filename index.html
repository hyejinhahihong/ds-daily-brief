★01AWS, Bedrock AgentCore로 '앰비언트 에이전트' 구현 — S3 이벤트가 곧 프롬프트, ask_human 툴로 승인 대기Building ambient agents with Amazon Bedrock AgentCore: From event-driven signals to human-in-the-loop workflows✍️ 블로그 · aws.amazon.com이 글은 Amazon S3 업로드, EventBridge 규칙, Lambda 트리거 같은 이벤트가 발생하면 자동으로 에이전트 작업이 생성되고 실행되는 '앰비언트 에이전트' 패턴을 소개한다.

에이전트는 이벤트를 신호로 받아 분석과 작업을 수행하다가, 필요할 때 단일 ask_human 툴을 호출해 사람의 승인이나 검토를 요청하고, 응답이 오면 멈췄던 지점부터 작업을 이어간다. AgentCore Runtime은 컨테이너 기반 실행 환경과 세션 격리, Bedrock 파운데이션 모델 연동을 제공해 장시간 실행되는 signal→agent→human-in-the-loop 흐름을 지원하며, 각 에이전트 턴은 Lambda의 15분 제한에 맞춰 캡핑된다. Lambda와 DynamoDB를 결합해 완전 서버리스 형태의 앰비언트 에이전트 플랫폼을 구성할 수 있다.

WHY IT MATTERS

채팅 기반 에이전트는 사람이 먼저 대화를 시작해야 하고, Step Functions 같은 완전 자동화 파이프라인은 모호한 상황에서 판단이나 질문을 못 한다는 한계가 있는데, 앰비언트 에이전트는 이 둘의 공백을 메워 대규모 문서·모니터링 업무의 수동 트리아지 시간을 줄여준다.

WHAT'S DIFFERENT

채팅 기반 에이전트는 사람이 대화를 시작해야 하고 한 번에 하나의 대화만 처리하는 반면, 앰비언트 에이전트는 이벤트 스트림을 직접 수신해 여러 이벤트를 병렬로 처리하며 필요할 때만 사람을 개입시킨다는 점에서 다르다.

WHY IT MATTERS

WHAT'S DIFFERENT

03Scaling Laws for Looped Mixture of Experts순환-희소성 결합 스케일링 법칙 공개 — Looped MoE, 추론 성능서 비순환 모델 대비 파라미터 2배 효율📄 논문 · arxiv.org이 연구는 순환(looping)과 MoE 희소성을 동시에 모델링하는 최초의 스케일링 법칙인 Loop Scaling Laws를 제안한다.

핵심은 희소성 조건부 순환 매핑으로, 순환이 만들어내는 유효 파라미터 증가와 희소성이 이를 더 키우는 방식을 수식화한다. 이 법칙은 기존 방법보다 looped 모델의 held-out loss를 더 정확히 예측하며, 기존 dense 및 MoE 스케일링 법칙을 특수 사례로 포함한다. 평가 결과 희소성은 활성 파라미터 효율을 약 3배, 순환은 추론 과제에서 전체 파라미터 효율을 약 2배 높이며, 두 축을 결합하면 성능 한계가 더 확장된다. 조 단위 토큰 규모 실험에서도 동일 학습 연산량 기준, 법칙으로 도출한 순환 구조의 looped MoE가 약 2배 큰 비순환 MoE와 동등한 추론 성능을 보이면서 테스트 시점 스케일링까지 가능했다.

WHY IT MATTERS

파라미터 수와 연산량을 늘리는 것 외에 순환 깊이와 희소성을 함께 설계 변수로 다룰 수 있다는 점에서, 제한된 메모리·연산 예산 내에서 모델 구조를 최적화하려는 실무자에게 설계 지침을 제공한다.

WHAT'S DIFFERENT

기존 스케일링 법칙은 순환(recurrence)과 희소성(sparsity)을 각각 별도로만 모델링했던 것과 달리, 이 연구는 두 축을 하나의 법칙으로 결합해 기존 dense 및 MoE 스케일링 법칙을 특수 사례로 포함한다.

02Removing Timing Shortcuts Improves Non-Invasive Brain-to-Text비침습 뇌-텍스트 디코딩의 '타이밍 지름길' 발견 — SimpleB2T, 실제 뇌 신호로 WER 36.6% 달성📄 논문 · arxiv.org연구진은 d'Ascoli et al.(2025)의 뇌-텍스트 디코딩 성능 향상이 실제로는 뇌 데이터 없이도 재현 가능함을 밝혔다.

기존 방법은 문장 내 모든 단어 윈도우를 함께 인코딩하는데, 인접 윈도우가 겹치면서 단어 간 시간 간격이 누출되고, 단어 길이가 단어마다 다르다는 점을 이용해 뇌 신호 없이도 예측이 가능해진다. 실제로 뇌 정보가 전혀 없는 합성 신호에서도 22.0% 균형 정확도를 얻어 실제 뇌 기록(22.3%)과 거의 차이가 없었다. 각 단어 윈도우를 독립적으로 처리하도록 바꾸자 모델은 진짜 뇌 신호 기반 정보를 학습하게 되었고, 단어별 다중 관측 집계와 사전학습 LLM 언어 사전 활용 전략이 훨씬 효과적으로 작동했다. 이 단순한 방식(SimpleB2T)은 단어당 5회 관측 조건에서 단어 오류율(WER) 36.6%를 달성해 침습적 디코딩 성능에 근접했다.

WHY IT MATTERS

뇌-텍스트 디코딩처럼 평가가 어려운 분야에서 벤치마크 수치가 실제 메커니즘이 아닌 데이터 누출에 의한 것일 수 있다는 경고 사례로, 시계열·신경 디코딩 연구에서 평가 설계의 함정을 점검할 필요성을 보여준다.

WHAT'S DIFFERENT

기존 d'Ascoli et al.(2025) 방식이 문장 내 모든 윈도우를 함께 인코딩해 단어 간 타이밍을 암묵적으로 노출시킨 것과 달리, 이 연구는 각 윈도우를 독립적으로 처리해 해당 지름길을 제거했다.
